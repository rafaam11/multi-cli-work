# v1.29.1 — 폴더 행이 두 줄로 갈라지던 문제 수정

사이드바에서 폴더 행이 펼치기 화살표만 있는 줄과 아이콘+이름 줄, 두 줄로 갈라져 보이는 문제를
고쳤다. 특히 선택하거나 마우스를 올린 행에서는 그 배경색이 두 줄 모두를 덮어 하나의 커다란 상자로
보이며 더 두드러졌다.

## 원인

`.project-row`가 1열 그리드였는데 자식은 두 개(펼치기 화살표 + 이름·아이콘 버튼)였다. 그리드에
열이 하나뿐이면 두 번째 자식은 다음 줄로 밀려난다 — 화살표 혼자인 줄, 그 아래 아이콘·이름 줄로
쪼개진 것이다.

이 1열 그리드는 9월 2일 "폴더가 이제 리프 노드라 select 버튼이 행의 유일한 자식"이라는 전제로
만들어졌는데, 이틀 뒤 폴더 아래 세션·문서·worktree 층을 되살리며 펼치기 화살표가 형제로 다시
들어왔고, 그리드는 그대로 남아 있었다.

## 변경 사항

- **폴더 행을 2열 그리드(26px + 나머지)로 되돌렸다.** 화살표와 이름 버튼이 다시 한 줄에 나란히
  선다
- **e2e 검증을 보강했다.** 기존 테스트는 이름 버튼의 너비만 쟀는데, 1열이든 2열이든 그 버튼 자체
  너비는 거의 행 전체였기 때문에(1열일 땐 자기 줄을 혼자 차지) 이번 회귀를 놓쳤다. 화살표와 이름
  버튼의 세로 위치가 같은 줄인지, 행 높이가 한 줄 높이(32px 이하)로 유지되는지까지 함께 확인한다
