# v1.55.0 — 세션 관제와 프롬프트 작업공간

Codex·Claude Code 세션의 탐색·전달·분기와 프롬프트 관리를 MCW 화면에서 이어서 처리할 수 있도록 했습니다.

- **세션 탐색**: 세션·폴더·브랜치 검색, CLI 필터와 세션 고정을 추가했습니다. `Ctrl+P`의 현재 저장소 필터는 연결된 worktree까지 포함하며, `Ctrl+Shift+P`에서 명령과 오른쪽 패널을 찾을 수 있습니다.
- **보류 메시지 관리**: 오른쪽 보류 탭에서 전달 이유를 확인하고 메시지를 수정·취소하거나 같은 대상 안에서 순서를 바꿀 수 있습니다. 팬아웃도 팀 보드·프롬프트와 같은 전달 큐를 사용하며, 지금 전달을 눌러도 사람의 입력·승인·CLI 대화상자가 끝날 때까지 기다립니다.
- **프롬프트 라이브러리**: 이름·태그 검색, 즐겨찾기, CLI 범위, JSON 가져오기·내보내기와 세션별 수동 초안을 지원합니다. 기존 팬아웃 템플릿은 처음 한 번 가져옵니다. CLI 명령 도우미에서 명령을 복사하고 터미널로 이동할 수 있습니다.
- **세션 인계와 대화 분기**: 선택한 터미널 출력·요청·관련 경로를 검토해 같은 폴더의 다른 세션에 인계할 수 있습니다. 저장된 대화 ID가 있는 유휴 Codex·Claude 세션은 새 대화로 분기하고 활동 탭에서 원본으로 돌아갈 수 있습니다.
- **활동 기록과 관제 요약**: 홈에서 상태별 세션 수를 보고 해당 세션으로 이동합니다. 활동 탭은 세션 정보, 관측된 모델·도구·작업 이벤트와 하위 에이전트를 표시하며 CLI 이벤트 기록을 최대 7일간 보관합니다. 하위 에이전트 이벤트가 부모 세션 상태를 덮어쓰지 않도록 했습니다.
- **사용량 이력**: 기존 사용량 갱신에서 관측한 Codex·Claude의 5시간·주간 한도를 24시간·7일 그래프로 표시합니다. 추가 조회 요청을 만들지 않으며, 초기화·관측 공백을 선으로 이어 추정하지 않습니다.
- **시작 프로필**: Codex·Claude별 모델 ID와 추론 수준을 저장하고 기본값을 고릅니다. 새 세션 선택창과 팀 프리셋 멤버별로 다른 프로필이나 CLI 자체 설정을 선택할 수 있습니다. 새 대화에만 적용하며 재개·분기는 CLI의 대화 설정을 따릅니다.
- **저장 배치와 화면 개인화**: 화면 분할·양쪽 사이드바 접힘·오른쪽 탭을 이름으로 저장하고 세션을 재시작하지 않고 복원합니다. 시각 효과·화면 밀도 설정과 설정 검색을 추가했으며, 애니메이션 감소 설정을 존중합니다.

**데이터와 한계**: 라이브러리·수동 초안·고정·분기 관계·프로필·배치는 별도 `workbench-state.json`에 원자적으로 저장하며 백업을 유지합니다. 보류 큐는 메모리에 있어 앱 재시작 시 남은 메시지가 복구되지 않습니다. 터미널 전달됨은 작업 실행 완료를 뜻하지 않습니다. 분기 대화는 같은 작업 폴더의 파일을 공유하며, 프로필의 모델·추론 수준 지원 여부는 설치된 CLI와 모델에 따라 다릅니다. 실시간 에이전트 트리, 프롬프트 빠른 슬롯·자동 초안, CLI 기능 진단, Claude 컨텍스트·캐시·비용 연동은 이번 버전에 포함되지 않습니다.

**검증**: Windows에서 Vitest 238개 파일·2,339개 테스트와 타입 검사·프로덕션 빌드를 통과했습니다. Electron 데스크톱 smoke 13개와 Codex hook E2E 1개에서 라이브러리 저장, 프로필 기본값·실행 인자, 분기 대화의 ID 분리, 배치 복원 전후 실행 중인 세션의 ID·PID 유지를 확인했습니다. Codex 실행기는 모의 실행기를 사용했으며 실제 계정의 모델을 호출하지 않았습니다. 검증 중 Windows 파일 교체와 스크롤 타이밍의 간헐 실패가 각각 한 번 있었고 재실행은 통과했습니다. CI에서 Windows·Linux 전체 테스트와 E2E, Android 서명 셸 및 설치 파일 패키징을 추가 검증합니다.
