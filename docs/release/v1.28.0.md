# v1.28.0 — 세션과 작업공간 통합

사이드바 위·아래에 나뉘어 있던 작업공간 선반과 세션 패널을 하나로 합쳤다. 기존 세션 패널의
상태 정보와 `대기 N`, `전체 | 여기` UI는 유지하면서, 상단 패널이 작업공간의 선택·정렬·숨김
동작을 직접 담당한다.

## 변경 사항

- 세션 패널을 프로젝트 트리 위로 옮기고 기존 작업공간 행과 하단 중복 패널을 제거한다
- 작업공간에 속한 세션과 문서를 저장된 슬롯 순서로 표시하며, 숨긴 패인은 별도 숨김 선반에만 둔다
- 패널 제목이나 행을 누르면 작업공간을 열고 해당 패인에 포커스한다
- 세션·문서 행의 눈 감김 버튼으로 실행이나 문서를 끝내지 않고 숨김 선반으로 이동한다
- 패널 행 사이 드래그로 작업공간 순서를 바꾸고, 숨김 패인을 세션 헤더에 놓아 되돌린다
- 접기 상태, 범위 필터, 대기 수, 상태·폴더·worktree 브랜치 표시는 그대로 유지한다
- 접힌 44px 사이드바 레일의 작업공간·숨김 바로가기는 기존 동작을 유지한다
