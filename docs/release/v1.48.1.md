# v1.48.1 — 앱 재시작 후 Claude Code 세션 재개 수정

앱을 껐다 켠 뒤 Claude Code 세션이 재개 버튼이나 자동 재개로 돌아오지 않던 두 경우를 고쳤다.

- **프롬프트를 보내기 전에 닫힌 세션**: Claude는 첫 프롬프트 전까지 대화를 저장하지 않아 `claude --resume`이 "No conversation found"로 바로 끝났고, 몇 번을 눌러도 같았다. 저장된 대화가 없으면 같은 세션 ID로 새 대화를 시작한다. 그 ID를 이전 대화가 이미 쓰고 있으면 새 ID를 발급한다.
- **`/clear` 뒤의 재개**: `/clear`는 같은 프로세스에서 새 대화 ID로 넘어가는데, 앱이 처음 ID를 계속 들고 있어 `/clear` 이전 대화가 열렸다. 이제 실행 중인 세션의 SessionStart 훅이 알려 주는 새 ID를 저장하고, 탭 제목도 새 대화를 따른다.

Claude Code 2.1.302 실제 CLI로 두 경우를 재현해 확인했고, 전체 단위 테스트 2,100개와 타입 검사를 통과했다. 상태 파일 형식과 폰 앱은 바뀌지 않았다.
