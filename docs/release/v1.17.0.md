# v1.17.0 — 파일 탐색기 개편, 패인이 스스로 알리는 대기 상태, 슬롯 압축

파일 탐색기가 VS Code의 Material Icon Theme 수준으로 바뀌고, 우클릭으로 파일을 실제로 다룰 수
있게 된다. 여기에 메인 그리드가 대기 상태를 스스로 알리는 테두리와, 프리셋 레이아웃에서 세션을
지웠을 때 빈칸이 남던 버그의 수정이 함께 나간다.

## 변경 사항

- **확장자마다 다른 아이콘이 붙는다.** 지금까지 트리는 lucide 아이콘 5종으로 모든 파일을 그려서
  `.ts`와 `.py`와 `.css`가 전부 같은 모양이었다. 이제 Material Icon Theme에서 뽑은 컬러 글리프가
  붙고, 폴더도 `src`·`docs`·`node_modules`처럼 이름에 따라 달라진다. 조회는 파일명 →
  복합 확장자(`.test.ts`, `.d.ts`) → 확장자 → 폴더명 순이고, 못 찾으면 예전 아이콘으로 돌아간다.
  글리프는 `npm run icons:extract`로 생성해 저장소에 커밋하므로 **런타임 의존성은 늘지 않는다**
- **트리가 읽히도록 정리됐다.** depth마다 세로 가이드 선이 서고, 행 높이·아이콘 크기·이름 대비를
  맞췄으며, 긴 이름은 말줄임 처리된다
- **git 상태가 트리에 보인다.** 수정은 amber, 추가는 green, 삭제는 red에 취소선이 붙고, 하위에
  변경이 있는 폴더에는 점이 선다. 무시된 경로는 흐려진다 — status를 `--ignored=matching`으로
  돌리기 때문에 `node_modules`는 레코드 하나로 끝나고 내부를 훑지 않는다
- **우클릭이 동작한다.** 파일·폴더·여백 각각에 맞는 메뉴가 열린다. **경로 복사·상대 경로 복사·
  이름 복사**, **탐색기에서 표시**와 **VS Code로 열기**, **이름 변경·복제·삭제**가 들어 있고,
  폴더에서는 **새 파일**과 **새 폴더**를 바로 만들 수 있다
- **이름은 트리 안에서 입력한다.** 새 파일·새 폴더·이름 변경 모두 다이얼로그 없이 그 자리에서
  타이핑하고, Enter로 확정, Esc나 포커스 이탈로 취소한다. 삭제는 **휴지통**으로 보내며 확인
  다이얼로그가 폴더의 하위 항목 개수까지 알려준다. 새 이름은 경로 구분자·`..`·널바이트·Windows
  예약어를 거부하고, 모든 조작이 기존 경로 탈출 방지 가드를 통과한다
- **열려 있던 탭이 트리를 따라간다.** 이름을 바꾸면 탭이 새 경로로 따라가고(레이아웃 슬롯과
  포커스까지 같이 갱신된다), 휴지통으로 보내면 탭이 닫힌다. 폴더를 지우면 그 아래 파일 탭도 함께
  닫히고, 저장하지 않은 편집이 있으면 기존 저장 확인 흐름이 먼저 뜬다
- **패인이 스스로 대기 상태를 알린다.** 지금까지 응답 대기는 좌측 사이드바에만 표시돼서 4분할에서
  어느 패인이 기다리는지 알려면 사이드바를 봐야 했다. 이제 **입력 대기는 violet**, **승인 대기는
  amber** 테두리가 은은하게 맥동하고, **오류는 red** 테두리가 정지 상태로 남는다. 포커스 링(teal)은
  그 위에 그대로 그려지고, 진행 중·대기·종료는 테두리를 그리지 않는다 — 진행 중이 teal이라
  포커스와 충돌하기 때문이다. `prefers-reduced-motion`에서는 맥동이 꺼진다
- **슬롯이 빈칸을 남기지 않는다(버그 수정).** 프리셋 레이아웃에서 세션을 닫거나 제거하면 그 자리가
  비어 있고 뒤 패인이 그대로 있었다. 이제 뒤 세션이 앞으로 당겨진다. 드래그 드롭도 자리를 맞바꾸지
  않고 **끼워넣어 뒤로 미는** 방식으로 바뀌었다
