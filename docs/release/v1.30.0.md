# v1.30.0 — 파일을 연결 프로그램으로 열기 + 에이전트 편집 강조

우측 사이드바 파일 탐색기에서 인앱으로 열 수 없던 파일을 외부 탐색기 더블클릭과 동일하게 열 수 있고, 세션 중 어떤 파일을 에이전트가 직접 고쳤는지 트리에서 바로 구분할 수 있다.

- 파일 트리에 "연결 프로그램으로 열기"를 추가했다. 우클릭으로 직접 열거나, 인앱 미리보기를 지원하지 않는 파일은 자동으로 넘어간다. OS가 실행해버리는 확장자(exe, bat, ps1 등)는 확인 모달을 거치고, 그 외 기존 단일 클릭 동작은 바뀌지 않는다.
- 설정에 "파일" 섹션을 추가했다. 확장자별로 기본 동작(인앱/OS/VS Code)을 지정하고, 미리보기가 불가능한 파일을 OS로 넘길지 여부를 토글한다.
- Claude·Codex 트랜스크립트를 기존 제목 폴링 주기에 얹어 tail로 읽어, 에이전트가 이번 세션에서 수정한 파일의 인덱스를 메모리에만 구성한다(디스크에 저장하지 않음).
- 파일 트리가 에이전트가 고친 파일과 그 외 세션 중 변경을 다른 색으로 표시하고, 상위 폴더까지 표시를 롤업한다(같은 폴더 안에 둘 다 있으면 에이전트 표시가 우선). "변경 표시 지우기" 버튼으로 한 루트의 표시를 초기화할 수 있다.

## 검증

- 전체 Vitest(117개 파일, 1336개 테스트) 및 TypeScript(main/renderer 양쪽) 통과
- 수동 E2E: OS 열기, 실행 확장자 확인 모달, 경로 가드, 확장자별 설정, 에이전트/그 외 변경 강조, 강조 지우기
