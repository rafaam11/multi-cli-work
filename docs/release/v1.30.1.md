# v1.30.1 — 세션·워크트리 안정성 및 Git 조회 개선

세션과 파일 탐색기의 늦은 응답이 현재 화면을 덮어쓰지 않도록 보호하고, 워크트리·미리보기·터미널 정리의 실패 재시도를 안정화했다.

- 폴더 전환, 파일 작업, HTML 미리보기의 오래된 응답을 무시하고 패널별 native view를 분리한다.
- 워크트리 삭제 실패 시 세션·기록을 보존하고, 외부 checkout 및 한글 브랜치를 올바르게 동기화한다.
- 터미널 세대별 release로 출력 버퍼·PTY·리스너를 해제하고, 저장 실패 출력은 재시도 가능하게 보존한다.
- 종료 단계 재시도와 자동 복원 직후 종료된 세션의 최신 출력 복원을 지원한다.
- 읽기 전용 Git 조회를 최대 4개까지 병렬화하면서 결과 순서와 저장소 소유권을 유지한다.

## 검증

- 전체 Vitest 120개 파일, 1,387개 테스트
- TypeScript 및 Electron production build
- Windows serial Electron E2E 19/19 통과
