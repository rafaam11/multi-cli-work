# v1.64.1 — 접힌 세션·배치 메뉴를 모든 화면 너비에서 안정화

공개 전 `v1.64.0` 릴리스 검증에서 좁은 중앙 작업영역의 접힌 메뉴를 일부 E2E가 기존 직접 버튼처럼 다루는 문제가 발견됐습니다. 사이드바를 넓힌 821–920px 작업영역에서는 전체 배치 미리보기가 새로고침 버튼을 덮을 수도 있었습니다. `v1.64.0`은 공개하지 않았으며, 이 패치가 반응형 헤더와 패인 상태 표시를 함께 담은 첫 공개 버전입니다.

- **화면 너비에 맞는 헤더 제어**
  - 중앙 작업영역이 920px 이하이면 전체 배치 미리보기를 현재 배치를 보여 주는 `배치` 메뉴로 접습니다.
  - 620px 이하에서는 기본·사용자 지정 CLI와 최근 폴더 시작을 `새 세션` 메뉴로 묶습니다.
  - 프로젝트명과 새로고침·상세·CLI 실행 버튼이 양쪽 사이드바 폭과 관계없이 서로 침범하지 않습니다.
- **직접 버튼과 접힌 메뉴를 같은 흐름으로 검증**
  - Electron E2E가 현재 화면 폭에 맞는 `새 세션`과 `배치` 제어를 선택하도록 공통화했습니다.
  - Windows와 Linux CI가 서로 다른 초기 창 크기를 사용해도 같은 사용자 동작을 검증합니다.
- **v1.64.0 기능 포함**
  - 프로젝트명을 우선하는 반응형 작업영역 헤더와 키보드로 조작할 수 있는 접힌 메뉴를 포함합니다.
  - 활성 패인 강조와 `작업 중`, `입력 대기`, `승인 대기`, `오류` 상태 배지를 포함합니다.

**호환성**
- 저장 형식·설정·IPC는 바뀌지 않았습니다.
- 기존 배치, 세션, 스크롤백 데이터는 그대로 사용합니다.

**검증**
- Windows에서 타입 검사와 프로덕션 빌드를 통과했습니다.
- Vitest 256개 파일·2,634개 테스트를 통과했습니다.
- 실제 Electron·PTY 전체 E2E에서 67건을 통과했고, 수동 시각 캡처용 1건은 기본 설정대로 건너뛰었습니다.
- 821–920px 중앙 작업영역에서 배치 미리보기가 새로고침 버튼을 가리지 않는 것을 터미널 재연결 시나리오로 확인했습니다.
