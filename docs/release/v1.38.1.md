# v1.38.1 — 터미널 포커스 중 단축키, Codex 상태 오인 수정

Orca·Ghostty·cmux 벤치마킹 조사 중에 찾은 버그 두 개를 고쳤다.

## 고친 것

- **터미널에 포커스가 있으면 세션 이동 단축키가 먹지 않았다**
  - 해당 단축키: Ctrl+Tab, Ctrl+Shift+Tab(다음·이전 세션)과 Ctrl+1~9(슬롯 포커스).
  - 이 키들은 사용자가 입력란에 글을 쓰는 동안에는 무시하게 되어 있다. 그런데 터미널(xterm)도 키 입력을 숨은 입력란(textarea)으로 받아서, 앱이 터미널 포커스를 "글 쓰는 중"으로 잘못 봤다. 패인을 클릭한 뒤에는 거의 늘 터미널이 포커스를 쥐고 있으니 사실상 동작하지 않았다.
  - 이제 터미널의 숨은 입력란은 예외로 둔다. 설정 창의 입력란이나 대화상자에서는 지금처럼 무시한다.
- **Codex 세션이 진행 신호를 받으면 "입력 대기"로 바뀌었다**
  - Codex는 OSC 9 알림으로 턴 종료와 승인 요청을 알리고, 앱은 그 알림을 상태로 읽는다.
  - 문제는 ConEmu 계열 터미널 신호도 같은 OSC 9 번호를 쓴다는 점이다. 진행률(`9;4;…`)이나 작업 폴더(`9;9;…`)처럼 숫자로 시작하는 명령이 들어오면 이것까지 알림으로 읽어, 작업 중인 세션을 대기로 표시했다.
  - 이제 숫자 명령은 건너뛴다.

## 바뀐 것

- **폰·원격 창 키 줄에 ←·→ 추가**
  - Esc·Tab 바로 뒤에 왼쪽·오른쪽 화살표를 넣었다. 입력 중인 프롬프트에서 커서를 옮기거나 좌우로 고르는 선택지를 다룰 때 쓴다.
  - 키 줄은 지금처럼 가로로 스크롤된다.
  - 이 화면은 호스트 PC가 띄워 주므로, 폰 앱은 업데이트하지 않아도 되고 호스트 PC만 이 버전이면 된다.

## 검증

- 단위 테스트를 추가했다: 숨은 입력란 판정, OSC 9;N 무시.
- Electron E2E `desktop.spec.ts`(22개)를 통과했다. 여기에 터미널 포커스 상태에서 Ctrl+Tab·Ctrl+Shift+Tab으로 패인 포커스가 옮겨지는 단계를 추가했다.
