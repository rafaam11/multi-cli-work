# v1.12.2 — 업무 프로젝트 참고 로컬 폴더

## 변경 사항

- 업무 프로젝트에 참고 로컬 폴더 목록 추가 — 프로젝트가 소유하지는 않지만 참고하는 이 PC의 폴더(각자 쓰는 자료 폴더, 공유 드라이브 마운트, 내려받은 산출물 폴더)를 라벨+경로로 등록
- 노션 링크와 같은 가벼운 참조 목록이라 `projects.json`에 등록되지 않음 — 사이드바에 뜨지 않고 세션도 열 수 없음
- 상세 페이지에서 폴더 선택 다이얼로그로 고르거나 경로를 직접 붙여넣어 등록, 행 단위로 추가·삭제하고 파일 탐색기에서 바로 열기 (blur 시 자동 저장, 경로가 빈 행은 저장 시 제외)
- 라벨을 비워 두면 폴더 이름이 라벨이 됨
- 세션 브리프에 `## 참고 로컬 폴더 (이 PC 기준, 읽기 참조용)` 섹션이 실려 CLI 에이전트가 그 폴더의 파일을 직접 참조 가능, 산출물을 그곳에 쓰지 않는다는 안내 문장이 함께 나감
- 탐색기 열기는 렌더러가 넘긴 경로를 그대로 열지 않고 해당 업무 프로젝트에 등록된 경로인지 확인한 뒤에만 연다 — 폴더 열기가 `projects:reveal`과 같은 규칙을 따름
- `work-projects.json`에 `localFolders` 키가 추가됨. 구버전으로 되돌리면 그 파일만 거부하고 `.bak`으로 폴백하며, 폴더 목록(`projects.json`)은 영향을 받지 않음
