# v1.8.1 — 터미널 스크롤 안정화

## 변경 사항

- Codex 동기화 출력 중 xterm.js의 화면 지우기 명령이 스크롤 위치를 초기화하던 문제 수정
- 실시간 출력과 재연결 replay에서 청크 경계를 넘어오는 제어 시퀀스를 안전하게 처리
- 일반 화면 지우기, PTY 원본 데이터, 로그와 상태 신호는 기존 동작 유지
- 사라진 worktree를 다시 만들었을 때 남아 있던 registry 항목을 자동으로 정합화
- 문서와 E2E fixture에 남아 있던 obsolete Orca 명칭 정리
