# v1.52.1 — 원격 창 완성도 개선

v1.52.0에서 넓은 화면 원격 창이 호스트 그리드를 따라 그리게 됐지만, 모양과 동작이 호스트와 어긋나는 곳이 많았다. 이번 판은 호스트 메인 창을 기준으로 원격 창을 맞춘다.

- **보이는 모습**: 원격 창이 호스트 테마(밝게/어둡게)를 따른다. 레이아웃은 호스트와 같은 타일 미리보기로 고른다. 빈 칸에는 칸 번호와 "새 세션" 버튼이 있다. 칸이 좁아지면 머리줄 도구를 차례로 숨겨 제목이 가려지지 않는다.
- **칸 크기**: 포커스가 없는 칸은 호스트 터미널 크기 그대로 그리고, 칸에 맞게 줄여 보인다. 창이 가로로 넘치거나 스크롤바가 생기지 않는다.
- **호스트와 같은 상태**: 호스트에서 칸을 확대하면 원격도 그 칸만 보이고, 원격에서 확대·해제할 수도 있다. 호스트에 시작 화면이 떠 있으면 원격도 그리드를 그리지 않는다. 호스트 창이 닫히면 원격은 예전 배치를 지운다.
- **원격 조작 오류 수정**:
  - 칸을 눌러 포커스를 옮겨도 호스트가 다른 폴더로 넘어가지 않는다.
  - 2쪽 이상에서 열을 나누거나 합쳐도 그 칸이 화면에서 사라지지 않는다.
  - 닫기를 두 번 눌러도 다음 칸까지 닫히지 않는다.
  - 호스트 창이 가려져 있어도 원격 조작이 바로 반영된다.
- **드래그 복사**: 원격 창에서 마우스로 여러 줄을 고른 뒤 Ctrl+C를 누르면 한 줄만 복사되거나 아무것도 복사되지 않던 문제를 고쳤다. 포커스가 없는 칸에서 바로 골라도 된다.

원격 화면은 호스트가 제공하므로 이 PC만 업데이트하면 된다.

**업데이트가 적용되지 않는 PC**: "재시작하여 업데이트"를 눌러도 버전이 그대로이면, 릴리스 페이지에서 `Multi-CLI-Work-Setup-1.52.1.exe`를 받아 직접 실행한다.
