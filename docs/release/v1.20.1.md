# v1.20.1 — 앱 전체 글자를 13px 체계로

화면마다 9px부터 18px까지 서로 다른 글자 크기가 섞여 있었고, 크기를 지정하지 않은 컨트롤은
브라우저 기본 16px로 튀었다. 이번 버전은 VS Code·JetBrains 계열 도구와 같은 **13px 중심의
컴팩트 UI**로 앱 전체 타이포그래피를 정리한다.

## 변경 사항

- **다섯 단계 글자 체계가 생겼다.** 페이지 제목 16px, 패널 제목 14px, 기본 UI 13px, 보조 UI
  12px, 캡션 11px을 의미 기반 토큰으로 정의했다. 버튼·입력·선택 상자·텍스트 영역은 기본 UI를
  상속하므로 지정이 빠진 텍스트가 더 이상 16px로 튀지 않는다
- **사이드바와 작업 영역의 계층이 선명해졌다.** 좌측 폴더·세션·파일 트리와 작업공간·패인 제목은
  13px을 기준으로 맞추고, 섹션명은 12px, 경로·시간·상태·배지는 11px로 내렸다. 현재 패인의
  폴더명과 업무 프로젝트명은 13px/600 및 프로젝트 색상 아이콘을 그대로 유지한다
- **Git 사이드바가 세 단계로 정리됐다.** `파일/Git`과 `변경사항/PR` 탭은 13px, 저장소·변경
  그룹 제목은 12px, 파일 경로·상태는 11px이다. 220px부터 480px까지 사이드바 폭을 바꿔도
  긴 저장소명·브랜치·파일명이 컨트롤을 밀어내지 않고 말줄임된다
- **콘텐츠 글자도 같은 기준을 쓴다.** xterm은 13px과 1.25 행 높이를 유지하고 Monaco Git diff는
  12px에서 13px로 커졌다. 일반 코드·텍스트 뷰어는 13px, Markdown 본문은 읽기 편한 14px이며
  문서 제목은 16/14/13/12px 계층을 따른다
- **너무 작은 문자를 없앴다.** 사람이 읽는 텍스트의 최솟값은 11px이고, 9.5·10.5·11.5px 및
  550·560·580·650 같은 중간값은 제거했다. 사용자가 쓰던 전체 UI 확대/축소 동작은 그대로다

## 호환성

- 공개 API와 상태 파일 형식은 바뀌지 않는다
- 색상, 컴포넌트 구조와 기능 동작은 그대로다
