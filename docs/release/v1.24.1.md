# v1.24.1 — 좁힌 사이드바에서도 텍스트가 얌전히 줄어들도록

좌측 사이드바를 드래그로 최소 너비(200px)까지 좁히면 바는 줄어드는데 안쪽 텍스트와 버튼은
그대로 남아 넘쳐흐르면서, 가로 스크롤과 뒤엉킨 레이아웃으로 UI가 깨져 보이던 문제를 고쳤다.

## 변경 사항

- **사이드바 상단 부제목("로컬 워크스페이스")이 두 번째 줄로 줄바꿈되지 않는다.** 형제 요소인
  타이틀에는 이미 있던 말줄임 처리가 부제목에는 빠져 있었다
- **"프로젝트" 섹션 라벨이 옆의 아이콘 버튼 3개를 밀어내지 않는다.** 좁은 너비에서는
  라벨이 먼저 말줄임된다
- **"모두"/"접기"/"작업중" 트리 컨트롤 버튼이 서로 겹치거나 사이드바 밖으로 삐져나오지
  않는다.** `flex: 1` 버튼에 `min-width: 0`이 빠져 있어 콘텐츠 고유 최소 폭 아래로 줄어들지
  못하던 게 원인이었다
- 위 세 곳 모두 코드베이스 전반에서 이미 쓰이던 축소 안전 패턴(`min-width: 0` +
  `overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`)을 동일하게 적용했다

## 호환성

- 순수 CSS 수정이며 동작, 상태, 저장 스키마, API 변경은 없다
- 사이드바 기본(264px) · 최대(420px) 너비와 접힌(rail) 상태의 표시는 그대로다
