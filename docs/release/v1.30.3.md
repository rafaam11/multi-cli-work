# v1.30.3 — 작업 경로에 따른 세션 소속 동기화

PowerShell 안에서 실행한 Codex·Claude가 워크트리로 작업 위치를 옮겼을 때, 사이드바 세션이 main에 남아 있던 문제를 개선했다.

- CLI가 보고한 작업 경로를 같은 저장소의 워크트리에 연결하고, 실행 중인 터미널과 세션 ID를 유지한 채 소속을 저장한다.
- CLI 종료 시 부모 PowerShell의 위치를 반영한다.
- 오래된 실행 세대·다른 대화·재개 전 기록이 현재 소속을 덮어쓰지 않도록 보호한다.
- PowerShell 연동은 인자, 파이프 입력과 종료 코드를 보존하며 사용자 프로필 파일을 변경하지 않는다.

## 적용 범위

업데이트 후 **새로 시작한 PowerShell 세션부터** 연동된다. Codex 훅은 정상적인 신뢰 승인 절차를 따른다. 사용자 지정 별칭·함수·`--profile`·`--settings` 또는 절대 경로 실행은 자동 연동을 우회할 수 있다. 작업 경로를 제공하지 않는 코드 모드·스크립트 실행은 자동 추적이 제한된다. [세부 동작](../session-workspace-tracking.md)
