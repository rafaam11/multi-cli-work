# v1.32.0 — 동기화·오케스트레이션 복구

2026-09-28 실사용 탐색에서 찾은 버그 가운데 우선순위가 높은 것들을 고친다. 워크스페이스 루트를 등록하면 곧바로 사이드바가 따라오고, 앱 안의 에이전트가 Git Bash에서도 `jk`를 쓸 수 있으며, 헤더와 세션 패널이 좁은 창에서도 제 폭을 지킨다.

- **워크스페이스 동기화가 곧바로 화면에 반영된다.** 설정 › 워크스페이스에서 루트를 추가하거나 다시 읽으면 main이 업무 프로젝트와 태그를 새로 쓰는데, 지금까지 사이드바는 시작할 때 읽은 목록을 들고 있어 재시작해야 새 프로젝트가 보였다. 이제 main이 동기화마다 변경을 알리고 앱이 업무 프로젝트·태그·워크스페이스를 다시 읽는다. 시작 시 백그라운드 동기화도 같은 알림을 보낸다.
- **상태 훅이 임시 파일을 남기지 않는다.** Claude가 도구를 병렬로 부르면 훅 여러 개가 같은 상태 파일로 동시에 이름을 바꾸려 하는데, 진 쪽의 `<id>.json.<pid>.tmp`가 영원히 남았다(한 설치본에서 188개 중 184개). 훅은 이제 실행마다 고유한 임시 이름을 쓰고, 이름 바꾸기를 재시도하며, 끝나면 임시 파일을 반드시 지운다. 앱 시작 시 정리도 1분 넘은 임시 파일을 쓸어 담는다 — 업데이트 뒤 첫 실행에서 쌓여 있던 잔해가 사라진다.
- **`jk`가 Git Bash에서도 잡힌다.** Windows에서 Claude Code의 Bash 도구는 Git Bash라 `.cmd`·`.ps1`을 이름만으로 실행하지 못했다. `userData/bin`에 확장자 없는 sh shim(`jk`, `jk-coding-cli`)을 함께 설치해 같은 PowerShell 클라이언트로 넘긴다.
- **인스턴스마다 제어 파이프가 따로 선다.** 파이프 이름이 `jk-coding-cli`로 고정이라, 설치본이 켜져 있는 동안 개발 빌드나 E2E 인스턴스는 `EADDRINUSE`로 `jk`를 잃었다. 이름에 userData 경로의 해시를 붙인다. 세션은 이름을 환경 변수로 받으므로 따로 할 일은 없다.
- **헤더가 작업 영역을 밀지 않는다.** 헤더가 자기 열보다 넓어 런처 행이 아이콘 하나 폭으로 눌렸고, 반쯤 가려진 런처에 포커스가 가면 작업 영역 전체가 20px 왼쪽으로 밀려 첫 패인이 사이드바 밑으로 숨었다. 작업 영역 열을 명시적으로 줄어들게 하고 잘라 내며, 제목이 먼저 폭을 내준다. 헤더가 좁아지면 런처 라벨(940px 이하), 상태 글자와 `상세` 라벨(820px 이하), 레이아웃 타일(780px 이하) 순으로 줄어들어 에이전트 버튼은 전부 한 번에 누를 수 있는 자리에 남는다.
- **세션 패널에서 이름이 먼저 보인다.** 폴더 접두어가 이름보다 먼저 줄어들고, 같은 폴더의 행이 이어지면 둘째 행부터 접두어를 생략한다(툴팁에는 남는다). 같은 에이전트 세션 다섯 개가 `Echo A…`로만 보여 구분되지 않던 문제다.
