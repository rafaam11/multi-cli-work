# v1.56.0 — 열 세로분할 배치 규칙 개선과 경로 복사

열을 세로분할한 화면에서 다른 열의 패인까지 밀려나던 문제를 고쳤습니다. 이제 패인이 들어오고 나갈 때 바뀌는 것은 해당 칸뿐입니다. 사이드바 우클릭 메뉴에는 경로 복사를 추가했습니다.

아래에서 `a/b`는 같은 열의 위아래, `|`는 열 경계, `_`는 빈 칸입니다.

- **빈 칸에 놓기**: 분할로 생긴 빈 칸에 새 세션을 열거나 패인을 놓으면 그 칸만 채웁니다. `a/_|b|c`의 빈 칸에 새 세션을 열면 `a/x|b|c`가 됩니다. 같은 화면에서 옮긴 패인의 출발 칸은 빈 칸으로 남습니다.
- **찬 칸에 놓기**: 같은 화면의 패인을 찬 칸에 놓으면 두 패인이 자리를 맞바꿉니다. 다른 곳에서 온 패인이면 원래 있던 패인이 첫 빈 칸으로, 빈 칸이 없으면 맨 뒤로 갑니다. v1.17.0부터 쓰던 끼워 넣기를 대체하며, 분할이 없는 배치와 가장자리 스냅 드롭에도 적용합니다.
- **패인이 떠날 때**: 분할된 열이 있는 배치에서는 패인을 닫거나 옮겨도 그 칸이 빈 칸으로 남고 다른 패인은 움직이지 않습니다. `a/b|c|d`에서 a를 닫으면 `_/b|c|d`입니다. 분할이 없는 고정 레이아웃과 자동 레이아웃은 지금처럼 뒤 패인이 당겨집니다.
- **분할 해제**: 두 칸이 다 찼으면 아래 패인이 바로 옆 열로 나갑니다(`a|b/c|d` → `a|b|c|d`). 이미 6열이면 맨 뒤로 갑니다. 한 칸이 비었으면 빈 칸만 없앱니다. 숨김에서 해제한 패인이 작업공간으로 넘어가거나, `_/a|c`에서 유일한 패인이 빠지던 문제도 고쳤습니다.
- **레이아웃 타일로 해제**: 분할이 있는 배치에서 분할 없는 타일을 고르면 분할이 남긴 빈 칸을 없애고 적용합니다. `a/_|b|c`에서 3열을 고르면 `a|b|c`입니다.
- **경로 복사**: 사이드바의 폴더·worktree·세션 우클릭 메뉴에 추가했습니다. 세션은 작업 폴더 경로를 복사하며, 같은 메뉴를 쓰는 패인 헤더 우클릭에도 나타납니다. 파일 트리의 복사와 같이 성공 표시는 없고 실패만 오류 배너로 알립니다.

**호환성**: 저장 형식과 마이그레이션은 바뀌지 않습니다. 저장된 배치는 그대로 열리고, 달라지는 것은 이후의 배치 동작입니다.

**한계**: 다음은 이 버전에서 해결되지 않았거나 확인하지 못한 부분입니다.

- 레이아웃이 화면 전체에 하나이므로 한 페이지에서 분할하면 다른 페이지의 패인도 다시 배치됩니다. 자동 레이아웃에서 분할한 뒤 해제해도 자동으로 돌아오지 않습니다.
- 위 패인을 옮겨도 아래 패인은 같이 움직이지 않고, 사이드바에 하위 세션으로 표시되지도 않습니다.
- 폴더 그리드에서 ✕로 비운 패인은 세션이 살아 있으므로, 폴더를 다시 열거나 새 세션이 생기면 첫 빈 칸으로 돌아옵니다. 이전에는 맨 뒤로 돌아왔습니다.
- 위아래가 모두 빈 열에는 해제 버튼이 없습니다. 레이아웃 타일로 풀 수 있습니다.
- 분할된 배치에서는 중간 페이지가 전부 비어도 남습니다.
- 사이드바 행 드롭으로 다른 선반에서 온 패인은 계속 끼워 넣습니다.

**v1.55.3 노트 정정**: 한계 항목의 "50x44가 51x44로 바뀌는 것을 관측"은 순서가 정확하지 않습니다. Linux CI 관측값은 새로고침 전 51x44, 직후 측정 50x44, 이후 51x44입니다.

**검증**: Windows에서 Vitest 245개 파일·2,489개 테스트, 타입 검사, 프로덕션 빌드를 통과했습니다. 격리된 Electron 앱에서 E2E 63개(`column-split` 18개, `desktop` 33개, 나머지 스펙 12개)를 통과했습니다. `column-split`은 수정 전 빌드에서 18개 중 14개가 실패했습니다. 시스템 클립보드를 덮어쓰는 `desktop`의 `pastes each Ctrl+V`, `remote-copy`, `remote-window`는 로컬에서 실행하지 않았습니다. 경로 복사와 폰 화면의 분할·해제는 App 수준 테스트로 확인했고 실제 화면에서 직접 누르지는 않았습니다. 패키징된 앱에서 직접 확인하지도 않았습니다. CI에서 Windows·Linux 전체 테스트와 E2E·패키징을 다시 수행합니다.
