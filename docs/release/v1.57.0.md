# v1.57.0 — 패인 세션 ID 표시와 복사

데스크톱 터미널 패인의 폴더·브랜치 정보 줄 오른쪽에 앱 세션 ID와 복사 버튼을 추가했습니다. 다른 AI 세션에 전체 ID를 전달해 기존 `jk_list`·`jk_read`·`jk_send`에서 사용할 수 있습니다.

- **ID 표시**: 앞 8자와 생략 기호를 표시하고, 8자 이하면 그대로 표시합니다. 마우스를 올리면 전체 ID가 나타납니다. Claude·Codex 대화 ID와는 다른 앱의 `session.id`입니다.
- **전체 ID 복사**: 복사 버튼은 이름·접두사·개행 없이 전체 ID만 복사합니다. 성공하면 2초간 체크 아이콘과 `복사됨`을 표시합니다. 실패하면 `복사하지 못했습니다. 다시 시도하세요.`를 표시하고 다시 누를 수 있습니다.
- **패인 배치**: 좁은 패인에서는 폴더 정보가 먼저 줄어들고 ID와 복사 버튼은 유지됩니다. 폴더 정보가 없거나 세션이 종료되어도 복사할 수 있습니다. ID 영역 조작이 패인 드래그나 이름 변경으로 이어지지 않도록 처리했습니다.

**호환성**: 공개 API, 저장 형식, 세션 ID 생성 방식과 `jk_read`의 조회 범위는 바뀌지 않습니다. 모바일과 참조 안내문 복사는 이번 변경에 포함하지 않습니다.

**한계**: 실제 데스크톱 화면에서 좁은 패인·긴 폴더명의 배치와 키보드 조작은 직접 확인하지 않았습니다.

**검증**: Windows에서 Vitest 245개 파일·2,493개 테스트와 타입 검사를 통과했습니다. 컴포넌트 테스트에서 축약 표시·전체 ID 툴팁·정확한 ID 복사·성공 안내 유지 시간·실패 후 재시도·여러 패인·종료된 세션·드래그 차단을 확인했습니다. Windows·Linux 전체 테스트와 Electron E2E·패키징, Android 셸 빌드는 CI에서 수행합니다.
