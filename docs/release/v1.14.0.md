# v1.14.0 — 세션 탭 + 슬롯 그리드 + 작업공간 3개

## 변경 사항

- **화면의 단위가 "폴더"에서 "손으로 고른 패인 묶음"으로 바뀌었다.** 폴더를 누르면 그 폴더의 세션이 **탭 한 줄**로 서고, 그 아래 **슬롯 그리드**에 올라온다. 세션 수가 배치를 정하던 v1.13.0의 자동 배치는 걷어냈다 — 이제 **레이아웃이 칸 수를 정한다**
- **레이아웃 줄이 그리드 위에 상시 노출된다.** **자동**과 1~6칸 프리셋(2칸 좌우·상하, 3칸 메인+우측 2·3열·상단 메인, 4칸 2×2·3열+우측 2분할·메인+우측 3·4열, 5칸 메인+우측 2×2·3열+가운데·우측 2분할·3열+하단 넓게, 6칸 3×2·2×3)을 한 번의 클릭으로 바꾼다. 미리보기 타일은 실제 그리드와 **같은 `grid-template-*` 값**으로 그려서 보이는 그대로 배치된다. 고른 배치는 **폴더마다·작업공간마다 따로** 기억된다
- **기본값 자동** — 페이지에 올라온 패인 수에 맞춰 1=전체 · 2=좌우 · 3=3열 · 4=3열+우측 2분할 · 5=3열+가운데·우측 2분할 · 6=3×2로 배치한다. 자동 뷰는 빈 칸을 남기지 않는다
- **넘치면 페이지네이션, 모자라면 빈 칸.** 세션이 칸 수보다 많으면 `◀ 2/3 ▶` 로 넘긴다(탭을 누르면 그 세션이 있는 페이지로 이동). 화면 밖으로 밀린 세션은 계속 살아 있고 스크롤백도 그대로다. 칸이 남으면 빈 칸이 **드롭 자리**로 남는다
- **작업공간1/2/3** — 사이드바 맨 위의 세 줄. 탭을 끌어다 놓으면 **여러 폴더의 패인을 한 화면에** 모을 수 있다(원본 폴더의 탭은 그대로 남는 참조). 작업공간도 폴더 뷰와 같은 껍데기이며 자기 레이아웃을 기억하고, 폴더 뷰와 달리 자동으로 채워지지 않는다
- **문서도 패인이다.** 우측 사이드바에서 연 파일·diff·커밋 그래프·PR이 세션과 같은 자격으로 슬롯을 차지한다. 코드를 띄운 채 옆에서 에이전트를 굴리는 배치가 그리드 안에서 끝난다(문서는 앱이 도는 동안만 유지되고 재시작하면 슬롯에서 빠진다)
- **패인 드래그로 자리 교환.** 패인 헤더를 끌어 다른 슬롯에 놓으면 자리가 바뀐다. 드래그 중에는 **윤곽선만** 움직인다 — 패인 크기가 바뀔 때마다 xterm→PTY resize가 연쇄로 도는 것을 막기 위해 실제 재배치는 드롭 순간 한 번뿐이다
- **보고된 버그 수정** — 세션 6개가 찬 폴더에서 새 세션을 만들면 그리드가 1패인으로 접히고 되돌릴 수단이 없던 문제. 새 세션을 드러내려 화면을 접는 동작(`revealNewSession`)과 패인 헤더의 **+N 교체 메뉴**를 함께 삭제했다. 새 세션은 빈 슬롯 또는 다음 페이지에 자연히 자리를 잡는다
- **✕ 의 의미가 "슬롯 비우기"로 바뀌었다.** 세션은 계속 돌고 탭도 남는다 — 다시 누르면 돌아온다
- **폴더 색이 자동이다.** 수동 완료 토글(○/✓)을 없애고, 그 폴더에서 에이전트가 **실제로 돌고 있을 때만** amber, 아니면 green으로 칠한다. 유휴 폴더를 흐리게 하던 처리도 뺐다(유휴가 기본 상태라 트리 대부분이 죽어 보였다)
- **탭을 누르면 사이드바가 알려 준다.** 그 패인에 포커스가 가고, 좌측 사이드바에서 해당 폴더 행이 **3초간 강조**된다(접혀 있던 상위 업무 프로젝트는 펼쳐지고 보이는 위치로 스크롤된다)
- **알림 판정은 "지금 보고 있는 페이지"를 기준으로 한다.** 현재 페이지의 슬롯에 떠 있지 않은 세션이 입력·승인 대기에 들어가면 알림이 뜬다. `terminals:set-visible-sessions` 계약은 그대로 재사용한다
- v1.13.0의 `visibleSessionIds` 상태는 상태 파일을 읽을 때 **작업공간1**로 흡수된다. 재시작하면 폴더 뷰·작업공간의 슬롯 배치와 레이아웃이 실존 세션만 남긴 채 복원된다
