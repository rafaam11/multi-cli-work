# v1.55.1 — 간결한 사이드바와 폴더 기록

세션과 터미널에 공간을 돌려주고, 흩어져 있던 메시지·전달 상태·활동을 현재 폴더의 기록으로 모았습니다.

- **왼쪽 사이드바**: 세션 검색·CLI 필터·고정을 제거하고 전체/대기와 `Ctrl+P` 탐색을 유지합니다. 즐겨찾기는 제목을 눌러 접고 펼칠 수 있으며, 접힘 상태를 다음 실행에도 기억합니다.
- **오른쪽 사이드바**: 파일·Git·기록 세 탭으로 정리했습니다. 기록은 현재 개별 폴더와 그 worktree의 메시지를 최신순으로 보여줍니다. 업무프로젝트 전체를 섞지 않으며, 홈에서는 폴더 선택 안내를 표시합니다.
- **전달 상태와 상세 활동**: 현재 보류·실패 항목이 있을 때만 접힌 요약을 표시합니다. 선택한 세션의 상세 활동도 필요할 때 펼칠 수 있습니다. 이전 실행의 보류 기록을 현재 대기 중인 메시지로 오인하지 않도록 상태 확인 불가를 구분합니다.
- **프롬프트와 보류 관리**: `Ctrl+Shift+P`에서 프롬프트 라이브러리·보류 메시지 관리 창을 엽니다. 기존 저장 프롬프트·수동 초안·편집·취소·순서 변경·지금 전달 기능을 유지합니다. 창을 닫거나 다른 창으로 전환해도 작성 중인 프롬프트를 보존합니다.
- **메시지 기록**: 프롬프트 전달은 기록에 한 번만 남깁니다. 원문과 수신자별 수정 전달문을 분리해 보존하고, 대상을 제거해도 큐의 원래 폴더 범위를 유지합니다. 기록 저장이 실패하면 전달을 중복 실행하도록 유도하지 않고 경고를 표시합니다.
- **호환성**: 저장 배치의 보드·보류·활동 탭은 기록으로, 프롬프트 탭은 파일로 복원합니다. 기존 고정 데이터는 보존하되 화면에는 사용하지 않습니다. 보드 API와 에이전트 간 전달 기능은 유지합니다.
- **모바일 개선 포함**: 앞서 작업한 업무프로젝트→폴더/worktree→세션 탐색 서랍, 터치 스크롤과 과거 터미널 출력 유지, 실제 화면에 보이는 세션의 대기 확인 처리를 함께 반영했습니다. 모바일 셸은 0.3.0입니다.

**데이터와 한계**: 보류 큐는 메모리에 있어 앱 재시작 시 복구되지 않습니다. 터미널 전달됨은 작업 완료를 뜻하지 않습니다. 이전 기록에 전달문 스냅샷이 없으면 당시 실제 전달문을 추정하지 않습니다.

**검증**: Windows에서 Vitest 243개 파일·2,373개 테스트, 타입 검사·프로덕션 빌드, Electron E2E 45개와 패키징된 앱 smoke 15개를 통과했습니다. 선택 실행용 원격 화면 캡처 1개는 기본 설정대로 생략했습니다. 1280×720·1366×768 화면과 좁은 사이드바를 확인했으며, Android 단위 테스트 51개·서명 APK 빌드와 고정 서명 인증서 검증도 통과했습니다. CLI hook 검증은 격리된 모의 실행기를 사용하며 실제 모델 계정 호출과 구분합니다. 릴리스 CI에서 Windows·Linux 전체 테스트와 E2E·패키징을 다시 수행합니다.
