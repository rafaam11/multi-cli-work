# v1.64.2 — 좁은 작업영역 헤더에서 버튼이 잘리지 않게

`v1.64.1` 릴리스 검증의 Windows E2E에서 문제가 발견됐습니다. 양쪽 사이드바를 펼친 900×600 창에서 중앙 작업영역은 412px입니다. 이때 `새 세션` 버튼이 헤더 오른쪽 끝을 5.6px 넘어 잘렸습니다. 원인은 두 가지입니다. 620px 이하에서 헤더 여백과 간격을 줄이는 규칙은 헤더 자신을 대상으로 해서 실제로 적용되지 않았습니다. 버튼 묶음은 줄어들지 않아서 남는 폭이 1px 안팎이었습니다. Windows CI는 한글 라벨을 로컬보다 약 8% 넓게 그려 그 폭을 넘었습니다. `v1.64.0`·`v1.64.1`은 공개하지 않았으며, 이 패치가 두 버전의 변경을 함께 담은 첫 공개 버전입니다.

- **좁은 헤더에서도 버튼이 헤더 안에**
  - 중앙 작업영역이 620px 이하이면 헤더 왼쪽 여백이 16px에서 10px로, 제목과 버튼 사이 간격이 16px에서 4px로 실제로 줄어듭니다.
  - 460px 이하에서는 `배치`·`새 세션` 버튼이 글자를 숨기고 아이콘만 보여 줍니다. 이름은 툴팁과 접근성 이름으로 남습니다.
  - 제목은 최소 140px를 지키고, 그보다 모자라는 폭은 버튼 묶음이 받습니다. CLI 실행 버튼 줄이 길면 헤더 밖으로 밀리지 않고 그 안에서 가로로 스크롤됩니다.
- **헤더 E2E 검사 강화**
  - 1280×820과 900×600 모두에서 실행 버튼 줄 밖의 헤더 버튼과 실행 버튼 줄 전체가 헤더 안에 있는지 확인합니다.
  - 각 버튼의 오른쪽 끝을 눌렀을 때 그 버튼이 눌리는지 확인합니다. 기존 경계 허용 오차 0.5px는 그대로입니다.
  - 경계 검사가 실패하면 헤더·제목·버튼·라벨의 폭을 함께 보고합니다.
- **v1.64.0·v1.64.1 변경 포함**
  - 반응형 작업영역 헤더, 키보드로 조작할 수 있는 접힌 `배치`·`새 세션` 메뉴, 활성 패인 강조와 상태 배지를 포함합니다.
  - 자세한 내용은 [v1.64.0](https://github.com/rafaam11/multi-cli-work/blob/main/docs/release/v1.64.0.md)·[v1.64.1](https://github.com/rafaam11/multi-cli-work/blob/main/docs/release/v1.64.1.md) 노트에 있습니다.

**호환성**
- 저장 형식·설정·IPC는 바뀌지 않았습니다.
- 기존 배치, 세션, 스크롤백 데이터는 그대로 사용합니다.

**검증**
- Windows에서 타입 검사와 프로덕션 빌드를 통과했습니다.
- Vitest 256개 파일·2,634개 테스트를 로컬과 Windows CI에서 통과했습니다.
- 실제 Electron·PTY 전체 E2E를 로컬 Windows와 Windows CI에서 각각 67건 통과했습니다. Linux CI에서는 62건을 통과했습니다. 수동 시각 캡처용 1건은 기본 설정대로 건너뛰었고, Linux에서는 PowerShell·Codex 훅이 필요한 5건도 건너뛰었습니다.
- `v1.64.1` CI에서 실패한 900×600 압축 헤더 검사와 그 뒤 실행되지 못한 7건이 Windows CI에서 통과했습니다.
- 로컬에서 배율 100%로 중앙 작업영역 헤더 폭을 372–992px 범위에서 3px씩 바꿔 가며 확인했습니다. 라벨 글자 간격을 1.5px 넓힌 경우까지 버튼이 헤더를 벗어나지 않았고, 제목은 32px보다 넓게 보였습니다.
