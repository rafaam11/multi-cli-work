# v1.7.0 — GitHub PR 리뷰 워크플로

## 변경 사항

- 우측 Git 패널에 `변경사항 | PR` 전환과 프로젝트별 GitHub remote·필터 저장 추가
- GitHub.com 및 GitHub Enterprise Server의 PR 목록, 개요, 대화·리뷰, 파일 diff, CI 체크 표시
- 일반 PR 댓글과 인라인 리뷰 스레드 답글 작성 지원
- Claude Code/Codex 선택 시 고정된 PR HEAD의 detached worktree와 한국어 리뷰 프롬프트 생성
- 진행 중 PR 리뷰의 재개, 프롬프트 다시 채우기·복사, 게시 확인과 dirty 확인을 포함한 명시적 정리 제공
- PR 리뷰 registry의 원자 저장·backup 복구와 앱 재시작 후 세션/worktree 복원 지원
- 추가 worktree가 없으면 평면 사이드바, 존재하면 `메인 + worktree` 계층으로 즉시 전환
- GitHub 오류 상태 구분, 외부 JSON 런타임 검증, 안전한 Markdown·외부 링크 처리 추가

## 릴리스 자산

- `Multi-CLI-Work-Setup-1.7.0.exe`
- `Multi-CLI-Work-1.7.0-linux-x64.deb` / `.AppImage`
- `latest.yml`, `latest-linux.yml` 및 생성된 blockmap

- 단위·렌더러 테스트, TypeScript typecheck, 프로덕션 빌드 통과
- GitHub remote 파서, `gh` 오류·JSON 변환, 리뷰 registry와 한국어 프롬프트 계약 검증
- Electron E2E 11개 시나리오 통과
