# v1.25.0 — 노션 링크에 제목 자동 채움과 통합 접근 여부 표시

업무 프로젝트 상세 페이지의 `노션 페이지` 행에 URL만 넣으면 그 페이지의 제목이 라벨로 들어온다.
제목 조회는 곧 **접근성 검증**이기도 하다 — 통합이 읽지 못하는 페이지는 노션 MCP도 쓰지 못하므로,
행마다 붙는 체크 표시가 "이 링크를 에이전트가 실제로 열 수 있는지"를 알려준다.

## 변경 사항

- **URL을 넣으면 제목이 라벨로 채워진다.** 노션 REST API로 페이지(또는 데이터베이스) 제목을
  조회한다. 현재 노션 링크(`app.notion.com/p/<32자리 id>`)에는 제목 slug가 없고, 인증 없이
  페이지를 받아오면 공개 페이지조차 일반 문구(`Notion | Where teams and agents work together`)만
  돌아오므로 API가 유일한 경로다
- **행마다 접근 상태가 표시된다.** 초록 체크는 통합이 그 페이지를 읽을 수 있다는 뜻이고(= 노션
  MCP로도 접근 가능), 주황 경고는 링크는 열리지만 통합에는 보이지 않는다는 뜻이다. 사유는
  노션 섹션 아래 한 줄로 나온다
- **자동 채움은 기본 라벨만 건드린다.** 라벨이 비어 있거나 그대로 `노션`일 때만 제목으로 채우고,
  손으로 지은 라벨은 자동 조회가 덮어쓰지 않는다. 행의 조회 버튼을 누르면 항상 덮어쓴다
- **설정에 `노션` 탭이 생겼다.** 통합 토큰을 입력·제거한다. 토큰은 저장 전에 노션에 한 번 물어
  유효성을 확인하므로, 오타 난 토큰이 저장돼 모든 행이 경고로 보이는 상황이 생기지 않는다
- 조회는 URL 입력이 멎고 800ms 뒤에 시작한다(자동 저장 400ms보다 길다) — URL을 타이핑하는
  동안 매 글자마다 요청과 저장이 연쇄되지 않는다. 노션의 요청 한도(초당 3회 수준)를 넘기지
  않도록 여러 링크는 직렬로 조회하고, 결과는 앱이 켜져 있는 동안 URL별로 재사용한다

## 토큰 보관

- 토큰은 **평문 설정 파일에 넣지 않는다.** Electron `safeStorage`로 암호화해
  `userData/notion-credentials.json`에 별도로 저장한다(`settings.json`은 사용자가 열어보는
  평문 파일이라 시크릿을 두지 않는다)
- OS에 키 저장소가 없어 암호화가 불가능하면 **평문으로 떨어지지 않고 저장을 거부**하며,
  설정 화면에서 입력 자체를 막는다
- 저장된 토큰은 렌더러로 돌려주지 않는다 — 화면은 "연결됨 / 설정되지 않음"만 안다.
  오류 메시지에도 토큰 문자열이 실리지 않는다
- 렌더러 CSP가 외부 요청을 막으므로 노션 호출은 전부 메인 프로세스에서 나간다

## 호환성

- 업무 프로젝트 레지스트리 스키마는 그대로다. 노션 링크는 여전히 `{ label, url }`만 저장하며,
  접근 상태는 디스크에 남기지 않는다(노션 쪽 공유 설정이 바뀌면 곧 낡는 값이다)
- 토큰을 넣지 않아도 기존 동작은 그대로다. 조회 버튼이 비활성 상태일 뿐 링크 열기·편집·저장은
  영향을 받지 않는다
- 노션 API 버전은 `2022-06-28`로 고정했다. 최신(2025-09-03)은 데이터베이스가 data source로
  갈라져 응답 구조가 달라진다
- **토큰만 넣으면 되는 것이 아니다.** 조회하려는 페이지마다 노션에서 `연결`에 해당 통합을
  추가해야 제목이 읽힌다. 추가하지 않은 페이지는 경고로 표시된다
- 노션 API는 권한 없는 리소스와 없는 리소스를 모두 404로 답한다(존재 여부를 숨긴다).
  둘을 구분할 수 없어 "통합에 연결되어 있지 않습니다"로 안내한다

## 검증

- Vitest 전체 통과 (98개 파일 1023테스트, 이전 988에서 35개 추가)
- 신규 테스트: URL→ID 파싱 4종 링크 형태와 뷰 ID 무시, 페이지→데이터베이스 폴백,
  401/403/429/타임아웃 분류, 토큰 저장 왕복과 **평문이 파일·오류 메시지에 남지 않음**,
  진입 시 자동 검증과 라벨 채움 규칙, 토큰 미설정 시 조회하지 않음
- `npm run typecheck` 통과
- 릴리스 CI가 Windows 2022와 Ubuntu 22.04 x64에서 전체 Electron E2E와 패키징을 재검증한다
- 실제 노션 토큰을 쓰는 GUI 실측은 하지 않았다 — 토큰 입력, 실제 페이지 제목 조회, 재시작 후
  체크 표시 복원은 설치 후 직접 확인해야 한다
