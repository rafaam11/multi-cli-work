# v1.34.0 — 찾기·테마·방해 금지

2026-09-28 탐색에서 모은 기능 후보를 넣는다. 긴 에이전트 출력을 다시 찾아 읽고, 밝은 화면에서 쓰고, 회의 중에는 알림을 재우고, 트레이에 숨긴 창을 키 하나로 불러온다. 그 과정에서 설정 › 파일 탭이 저장되지 않던 버그도 고쳤다.

## 새 기능

- **터미널 스크롤백 찾기** — 터미널 안에서 `Ctrl+F`(또는 편집 → 찾기)를 누르면 패인 오른쪽 위에 찾기 막대가 뜬다. Enter·Shift+Enter로 결과 사이를 오가고, 대소문자 구분을 켤 수 있으며, 결과가 없으면 그렇게 말한다. Esc로 닫으면 키보드가 터미널로 돌아간다. 좁은 패인에서는 막대가 두 줄로 접힌다. (`@xterm/addon-search` 0.16.0 — xterm 6.0.0과 짝인 버전. 찾기를 처음 열 때만 싣는다.)
- **라이트 테마** — 설정 › 일반 › 테마에서 다크(기본값)·라이트·시스템 설정 따르기를 고른다. 시스템을 고르면 OS 설정이 바뀔 때 함께 바뀐다. 터미널 팔레트와 diff 뷰(Monaco)도 따라 바뀌며, 터미널은 다시 만들지 않아 스크롤백이 그대로다. 마지막 테마를 기억해 두어 시작할 때 어두운 화면이 번쩍이지 않는다.
- **알림 방해 금지** — 설정 › 알림에 매일 반복되는 방해 금지 시간대(자정을 넘을 수 있다)와 **1시간 끄기**가 생겼다. 트레이 메뉴에서도 끄고 켤 수 있다. 데스크톱 알림만 멈추고 배지·트레이·작업표시줄 표시는 계속 선다.
- **창 불러오기 단축키** — 설정 › 일반에서 Ctrl이나 Alt가 들어간 키를 지정하면 트레이에 숨어 있을 때도 그 키로 창이 뜬다. 다른 프로그램이 이미 쓰는 키는 저장하지 않고 이유를 알려 준다.
- **스크롤백 저장** — 세션 우클릭 → 스크롤백 저장…은 색·커서 제어 문자를 걷어 낸 텍스트 파일을 저장 대화상자로 원하는 곳(기본 다운로드 폴더)에 쓴다.
- **팬아웃 프롬프트 템플릿** — 프롬프트 팬아웃 대화상자에서 지금 쓴 프롬프트를 이름 붙여 저장하고, 불러오고, 지운다. 같은 이름으로 저장하면 고쳐 쓴다.
- **세션 패널 "대기" 필터** — `전체 | 여기` 옆의 **대기** 토글이 입력·승인을 기다리는 세션만 남긴다. 재시작 후에도 기억된다.

## 버그 수정

- **설정 › 파일 탭이 저장되지 않았다.** 설정 IPC 검증 목록에 `files`가 빠져 있어, 확장자별 열기 방법과 "미리보기를 지원하지 않는 파일은 연결 프로그램으로 열기"의 모든 변경이 `Settings patch contains unknown fields: files`로 거부됐다(이 탭이 생긴 v1.30.0부터). 이제 검증을 거쳐 저장된다.
- **설정 저장 실패 문구**가 "설정 저장에 실패했습니다" 한 줄뿐이던 것을 main이 준 이유(예: 다른 프로그램이 쓰는 단축키)까지 보여 주도록 바꿨다.
- 헤더의 레이아웃 타일이 940px 이하에서 먼저 작아져, 기본 창 크기에서 앞선 조작으로 사이드바 폭이 바뀐 상태에서도 에이전트 런처가 모두 보인다.

## 검증

- 전체 Vitest(128개 파일, 1,514개 테스트) 및 TypeScript(main/renderer 양쪽) 통과
- Electron E2E 전체 통과(24개) — 스크롤백 찾기(좁은 패인 포함) 테스트 추가, 헤더 컨트롤 겹침 검사 추가
- 라이트 테마는 홈·터미널(ANSI 색)·문서·Git 패널·설정 화면을 격리 인스턴스로 띄워 눈으로 확인
- 전역 단축키 실제 등록과 트레이 메뉴의 알림 끄기는 설치본에서 수동 확인 필요
