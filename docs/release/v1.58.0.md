# v1.58.0 — 터미널의 로컬 파일 경로 Ctrl+클릭

MCW 세션이 출력한 로컬 파일·폴더 경로를 Ctrl+클릭해 열 수 있습니다. 프로젝트 밖에서 만든 결과물도 절대 경로로 가리키면 열립니다.

- **경로 인식**: Windows 절대 경로, 세션 작업 폴더 기준 상대 경로, 한글·공백이 들어간 파일 및 폴더 경로를 인식합니다. 실제로 존재하는 항목만 링크로 표시합니다.
- **열기 동작**: 파일은 OS 기본 앱으로, 폴더는 탐색기로 엽니다. 연결 앱으로 열지 못한 파일과 실행 파일·스크립트는 탐색기에서 선택합니다.
- **소스 위치**: 프로젝트 내부의 `src/app.ts:42` 같은 줄 번호 링크는 기존처럼 MCW에서 해당 위치를 엽니다. 일반 웹 링크와 텍스트 선택 동작도 유지합니다.

**호환성**: 저장 형식은 바뀌지 않습니다. 터미널 경로 조회·열기용 내부 IPC가 추가되었습니다.

**한계**: 원격 머신이나 WSL 내부 경로를 로컬 경로로 변환하지 않습니다. 실제 패키징 앱에서 Ctrl+클릭 동작은 직접 확인하지 않았습니다.

**검증**: Windows에서 Vitest 246개 파일·2,496개 테스트, 타입 검사와 프로덕션 빌드를 통과했습니다. Windows·Linux Electron E2E와 패키징, Android 셸 빌드는 릴리스 CI에서 수행합니다.
