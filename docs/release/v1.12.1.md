# v1.12.1 — 업무 프로젝트 구분 색상

## 변경 사항

- 업무 프로젝트의 구분(정부지원과제·외주개발·상품개발·기타)이 색으로 즉시 구분 — 사이드바 그룹 헤더부터 하위 폴더까지 이어지는 세로 레일과, 구분 이름이 적힌 색상 칩
- 홈 대시보드 카드와 업무 프로젝트 상세 페이지에도 같은 색이 적용, 상세 페이지에서는 구분 select를 바꾸는 즉시 칩과 카드 테두리 색이 따라옴
- 그룹 선택 표시가 고정 teal에서 해당 구분 색으로 통일 — 기존 좌측 인디케이터가 새 레일과 같은 위치라 두 줄로 겹쳐 보이던 문제를 배경 농도 + 링으로 대체
- 완료·보관 상태의 업무 프로젝트 그룹은 흐리게 표시하고 hover·포커스 시 원복
- 미분류 그룹은 기타(회색 실선)와 헷갈리지 않도록 점선 레일 — 색이 아니라 형태로 구분
- 오류를 뜻하는 `--red` 계열과 분리된 전용 카테고리 팔레트, 네 색 모두 사이드바 배경 대비 4.5:1 이상
- 제안 4종 밖의 커스텀·레거시 구분은 색을 잃지 않고 기타와 같은 회색으로 표시
- 구분 라벨은 창 폭과 무관하게 항상 노출되어, 색이 단독으로 의미를 지지 않음
