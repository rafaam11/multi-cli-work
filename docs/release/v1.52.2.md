# v1.52.2 — 업데이트 설치 실패 안내

일부 PC에서 "재시작"을 눌러도 자동 설치가 조용히 실패하고 이전 버전이 그대로 다시 켜졌다. 앱은 실패를 몰랐기 때문에 같은 업데이트를 또 내려받았고, 사용자는 이유를 모른 채 같은 일을 되풀이했다.

- **설치 실패 감지**: 재시작으로 설치를 시작할 때 목표 버전을 기록해 둔다. 다음 실행에서 버전이 바뀌지 않았으면 업데이트 표시가 "{버전} 설치 실패"로 바뀐다.
- **수동 설치 안내**: 이때 버튼이 "수동 설치"로 바뀌고, 누르면 릴리스 페이지가 열린다. 그 실행에서는 자동 확인을 건너뛴다. 다음 실행부터는 평소처럼 확인한다.
- **기록**: 설치 시도와 실패는 `logs/updater.log`에 남는다.

**이미 설치가 안 되는 PC**: 1.52.1 이하에는 이 안내 기능이 없다. 릴리스 페이지에서 `Multi-CLI-Work-Setup-1.52.2.exe`를 받아 직접 실행한다.
