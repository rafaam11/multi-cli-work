# v1.22.1 — 다시 켜도, 입력은 살아 있다

앱을 종료했다가 다시 켠 뒤 Codex 세션이 정상적으로 재개됐는데도 패인이 `종료됨`으로 남아,
프롬프트에 글자가 찍히지 않는 경우가 있었다. 실제 PTY는 입력을 받을 준비가 됐지만 화면이 이전
종료 상태를 고수하면서 키 입력을 버린 것이 원인이었다.

## 변경 사항

- **종료 중 중단된 세션의 활성 상태를 화면에도 반영한다.** 재시작 후 attach가 Codex 세션을
  `입력 대기 중` 또는 실행 중 상태로 복구하면, 패인이 더 이상 이전 `종료됨` 상태에 머물지 않는다
- **복구 직후 바로 키보드 입력을 보낼 수 있다.** 활성 상태가 반영되면서 터미널의 읽기 전용 제한이
  풀리고, 포커스된 패인에서 입력한 문자가 정상적으로 Codex PTY로 전달된다
- **실제로 종료된 세션은 되살리지 않는다.** attach 응답을 기다리는 사이 종료 이벤트가 도착한 경우
  늦게 온 활성 응답이 종료 상태를 덮어쓰지 않도록 경합 조건을 보호했다

## 호환성

- 터미널 세션 저장 형식, IPC API, Codex 프로필과 훅 형식은 바뀌지 않는다
- 기존 `v1.22.0` 세션은 별도 마이그레이션 없이 다음 실행부터 수정된 복구 경로를 사용한다

## 검증

- 재시작 중단 세션이 attach 후 입력을 받는 회귀 테스트 추가
- attach 도중 실제 종료된 세션은 읽기 전용으로 남는 경합 테스트 추가
- Vitest 전체, TypeScript typecheck, 프로덕션 빌드와 Electron E2E 검증
