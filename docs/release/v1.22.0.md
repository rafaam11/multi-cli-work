# v1.22.0 — 헤더에서 시작하고, 한 번에 다시 그린다

작업공간과 숨김은 여러 폴더의 패인을 함께 담는 선반이라, 지금까지 헤더에는 시작 버튼이 없었다 —
"여기"가 어느 폴더인지 화면이 말해 주지 않았기 때문이다. 그래서 선반을 보다가 세션 하나를 더
열려면 사이드바로 돌아가 폴더를 찾아야 했다. 이번 버전은 **포커스된 패인이 곧 "여기"** 라고
정하고 런처를 선반으로 데려온다. 같은 헤더에서 새로고침도 정리했다 — 창 전체를 다시 그리는 일에
패인마다 버튼이 하나씩 있을 이유가 없다. 그리고 앱을 껐다 켰을 때 패인이 깨져 보이던 원인을
고쳤다.

## 변경 사항

- **작업공간·숨김 헤더에도 에이전트 런처가 선다.** 포커스된 패인과 **같은 폴더·같은 worktree**에서
  새 세션을 연다. 버튼 툴팁이 "〈패인 이름〉와 같은 경로에서 〈에이전트〉 시작"으로 어디에 생길지
  말해 주고, 포커스가 옮겨 가면 겨냥도 따라 옮겨 간다. 포커스된 패인이 없거나 문서 패인이면 런처는
  나오지 않는다 — 선반에서는 포커스 말고 "여기"를 말해 주는 것이 없다
- **레이아웃이 `자동`일 때 `＋ 새 세션` 버튼이 하나 더 붙는다.** 누르면 빈 슬롯의 그것과 같은
  **최근 폴더 팝오버**가 버튼 아래에 열린다. `자동`은 빈 칸을 남기지 않으므로 — 빈 칸의 ＋ 가 원래
  그 목록으로 가는 유일한 길이었다 — 이 버튼이 자동 배치에서의 입구다
- **어느 쪽으로 시작하든 화면은 움직이지 않는다.** 세션은 배경으로 시작해 보고 있던 배치의 끝에
  붙고, 동시에 자기 폴더의 그리드에도 자리를 받는다. 페이지·선택한 폴더·활성 뷰는 그대로다
- **새로고침이 헤더의 `⟳` 하나로 모였다.** 화면에 보이는 패인을 **전부** 지금 창 크기에 맞춰 다시
  그린다. 세션은 건드리지 않는다 — 끝난 세션은 끝난 채로 다시 그려지고 `⟲ 재개`는 그대로 남는다.
  이미 새로고침 중인 세션은 건너뛰고, 하나라도 도는 동안 버튼은 비활성이다
- **패인 헤더의 `⟳` 버튼은 제거했다.** 새로고침은 그 패인이 지금 가진 크기에 맞춰 터미널을 다시
  세우는 일이라 세션보다 창에 속한다. 한 패인만 다시 그릴 일은 남아 있으므로 **패인 헤더 우클릭 →
  새로고침** 과 타이틀바 **세션** 메뉴의 항목은 그대로 둔다. `⟲ 재개`·`⏹ 중지`처럼 세션 하나에
  대한 조작은 계속 패인 헤더에 있다
- **재시작 후 자동 재개되는 세션이 그 패인의 크기로 뜬다.** 지금까지는 재개되는 프로세스가 80×24로
  시작해, 복원된 스크롤백과 새 출력이 실제 패인보다 좁은 폭으로 접힌 채 그려졌다 — 나중에 크기를
  바꿔도 이미 나온 출력의 줄바꿈은 되돌릴 수 없어서, 매번 손으로 새로고침을 눌러야 했다. 이제
  패인이 자기 크기를 재고 나서 붙고, 그 크기가 재개되는 PTY까지 그대로 전달된다
- **Codex 훅이 Windows에서 `.cmd` 러너를 거친다.** PowerShell 한 줄에 실행 경로를 인용해 넣던
  방식을 `provider-hooks\codex-session-start.cmd` 배치 파일로 바꿨다. 프로필을 다시 쓸 때
  `[hooks.state]` 블록을 읽어 보존하므로, 한 번 신뢰한 훅이 앱을 켤 때마다 다시 물어보지 않는다

## 호환성

- `terminals.attach(sessionId)`가 **선택적** 두 번째 인자 `{ cols, rows }`를 받는다. 크기를 넘기지
  않으면 코디네이터가 종전과 같은 80×24 기본값을 쓴다 — 렌더러가 아직 패인을 잴 수 없는 시점의
  경로가 그대로 살아 있다. `terminals:refresh`는 부작용 없는 기존 attach를 그대로 쓴다
- 상태 파일 형식과 배치 저장 방식은 바뀌지 않는다. 슬롯 그리드·드래그 앤 드롭·스냅 존·페이지네이션
  동작도 건드리지 않았다
- 패인 헤더에서 사라진 것은 `⟳` 버튼 하나뿐이다. 폴더 화면 헤더의 런처는 종전과 같이 그 폴더에서
  시작한다
- 기존 Codex 프로필(`multi-cli-work.config.toml`)은 다음 실행 때 새 형식으로 다시 써진다. 이미
  신뢰해 둔 훅 상태는 옮겨 붙는다

## 검증

- Vitest 전체 통과 (91파일 924테스트) — 지연 재개가 attach가 실어 보낸 크기로 PTY를 띄우는 것과
  크기가 없을 때 80×24로 물러서는 것, IPC가 cols/rows를 숫자로 검증해 넘기는 것, 헤더 `⟳` 가 보이는
  패인 전부를 다시 그리고 패인 헤더에는 버튼이 없는 것, 선반 런처가 포커스를 따라 겨냥을 옮기고
  포커스된 패인의 폴더에서 배경으로 시작하는 것, `새 세션`이 `자동`에서만 나오고 최근 폴더 목록을
  여는 것을 새 테스트로 덮었다
- TypeScript typecheck 통과
- 릴리스 CI가 Windows 2022와 Ubuntu 22.04 x64에서 전체 Electron E2E와 패키징을 수행했다
