# v1.64.0 — 좁은 세션 화면에서도 현재 작업을 놓치지 않게

양쪽 사이드바를 펼친 작은 Windows 창에서는 프로젝트·세션 제목이 사라지고, 배치 미리보기와 실행 버튼이 서로 침범할 수 있었습니다. 세션이 여러 개일 때는 패인 헤더만 보고 어느 세션이 작업 중이거나 사용자 입력을 기다리는지도 빠르게 구분하기 어려웠습니다.

- **반응형 작업영역 헤더**
  - 창 전체가 아니라 중앙 작업영역 너비를 기준으로 헤더를 전환합니다.
  - 820px 이하에서는 전체 배치 미리보기를 현재 배치를 보여 주는 `배치` 메뉴로 접습니다.
  - 620px 이하에서는 등록된 기본·사용자 지정 CLI와 최근 폴더 시작을 `새 세션` 메뉴로 묶습니다.
  - 프로젝트명이 세션명과 경로보다 먼저 공간을 확보하며, 긴 이름은 말줄임과 전체 이름 툴팁으로 확인할 수 있습니다.
- **키보드로 쓸 수 있는 접힌 메뉴**
  - 마우스와 키보드로 배치와 새 세션 항목을 열고 선택할 수 있습니다.
  - 화살표 키로 항목을 이동하고 `Esc`로 닫으면 원래 실행 버튼으로 초점이 돌아갑니다.
- **패인 상태 가독성**
  - 활성 패인에 기존 강조색의 얇은 테두리와 헤더 배경을 적용했습니다.
  - `작업 중`, `입력 대기`, `승인 대기`, `오류`를 짧은 텍스트 배지로 표시합니다.
  - 모션 감소 설정에서도 상태와 활성 패인 구분은 정적으로 유지됩니다.

**호환성**
- 저장 형식·설정·IPC는 바뀌지 않았습니다.
- Windows 데스크톱 세션 화면만 바뀌며 기존 배치, 세션, 스크롤백 데이터는 그대로 사용합니다.

**검증**
- Windows에서 타입 검사와 프로덕션 빌드를 통과했습니다.
- Vitest 256개 파일·2,634개 테스트를 통과했습니다.
- 실제 Electron·PTY를 사용하는 데스크톱 E2E 35건과 패인 분할 E2E 18건을 통과했습니다.
- 양쪽 사이드바를 펼친 1280×820·900×600에서 긴 프로젝트명, 페이지 탭, 사용자 지정 CLI, 배치·새 세션 메뉴의 가시성과 겹침을 확인했습니다.
