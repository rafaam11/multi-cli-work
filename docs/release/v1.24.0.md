# v1.24.0 — 사이드바에서 패인을 원하는 순서로

사이드바의 `작업공간`과 `숨김` 목록은 지금까지 패인을 열거나 숨기는 입구였지만, 표시 순서를
직접 다듬을 수는 없었다. 이번 버전부터 펼친 목록의 세션과 문서를 위아래로 끌어 놓으면
원하는 위치에 삽입되고, 바뀐 순서가 중앙 그리드와 저장 상태에 즉시 반영된다.

## 변경 사항

- **모든 패인 행을 드래그해 재정렬할 수 있다.** 터미널 세션뿐 아니라 Markdown 등 문서
  패인에도 같은 동작을 적용했다
- 행의 위쪽 절반에 놓으면 해당 패인 앞에, 아래쪽 절반에 놓으면 뒤에 삽입된다. 드롭할
  위치에는 가로 삽입선이 나타나 결과를 미리 보여준다
- 같은 목록 안에서 옮기면 `작업공간` 또는 `숨김`의 순서만 바뀐다. 이 순서는 중앙 그리드의
  슬롯 순서와 동시에 갱신된다
- 다른 목록의 행에 놓으면 `작업공간`과 `숨김` 사이 이동과 지정 위치 삽입을 한 번에 수행한다
- 목록 헤더에 놓아 끝에 추가하는 기존 동작과 중앙 그리드 안의 드래그 동작은 그대로 유지된다
- 재정렬 결과는 기존 슬롯 저장 경로로 기록되어 앱을 다시 시작해도 유지된다

## 호환성

- 외부 API와 저장 스키마 변경은 없다. 기존 `workspace`와 `hiddenPanes` 상태를 그대로 사용한다
- 슬롯의 빈자리와 페이지 구조를 보존하므로 재정렬하지 않은 패인의 배치는 달라지지 않는다
- 패인 선택·포커스, 실행 중인 PTY, 문서 상태는 재정렬 중에도 유지된다
