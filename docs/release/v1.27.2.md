# v1.27.2 — 사이드바 폴더 아이콘 정렬 보정

v1.27.1에서 폴더 선택 버튼의 전체 너비를 복구했지만, 버튼 안쪽의 아이콘은 옛 펼침 버튼 뒤에 서던
시절의 왼쪽 여백 `0`을 그대로 썼다. 이 때문에 GitHub·Teams·일반 폴더 아이콘이 행 왼쪽의 4px 활동
상태 레일과 겹쳐 하나의 꺾인 선처럼 보였다.

## 변경 사항

- 폴더 선택 버튼에 왼쪽 8px 여백을 적용해 아이콘을 활동 상태 레일과 분리한다
- 폴더 버튼이 행 전체 너비를 쓰는 기존 보장은 유지하면서, 아이콘 inset도 Electron E2E에서 검증한다
- 오른쪽 읽지 않음 점과 세션 수의 정렬은 바꾸지 않는다

## 릴리스 자산

- `Multi-CLI-Work-Setup-1.27.2.exe`
- `Multi-CLI-Work-1.27.2-linux-x64.deb` / `.AppImage`
- `latest.yml`, `latest-linux.yml` 및 Windows blockmap

## 검증

- Vitest 전체 통과 (106개 파일, 1151개 테스트)
- TypeScript typecheck 및 프로덕션 빌드 통과
- Electron E2E 전체 통과 (18개): 수정 전 아이콘 inset `0px` 실패를 재현하고 수정 후 `8px` 확보를 확인
