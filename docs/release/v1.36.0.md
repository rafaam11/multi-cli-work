# v1.36.0 — 다른 PC에서 세션 이어받기

집에서 회사 PC(또는 반대)에 돌려 둔 claude·codex 세션을 **다른 PC의 앱에서 열어 이어서 작업한다.** 폰 컴패니언이 하던 일을 키보드와 큰 화면이 있는 PC에서 하는 것이다. 두 PC는 Tailscale로 묶여 있다는 전제이고, 공인 인터넷에는 아무것도 열지 않는다. 원격에서 세션을 새로 띄우고 정리할 수 있게 됐고, 원격 창을 닫아 둬도 그 PC의 세션이 사람을 기다리면 알림이 온다. 세션 관리 기능은 PC가 서빙하는 화면에 들어가므로 **폰에서도 같이 쓸 수 있고, 폰 앱(0.1.1)은 그대로다.**

설계: [`docs/superpowers/specs/2026-10-03-remote-pc-window-design.md`](../superpowers/specs/2026-10-03-remote-pc-window-design.md) · 사용법: [설치 문서의 "다른 PC에서 이어받기"](../installation.md#다른-pc에서-이어받기)

## 새 기능

- **원격 PC 등록** — 설정 탭 "모바일"이 **"원격"**으로 바뀌고 둘로 나뉜다. **이 PC에 접속 허용**은 기존 그대로(체크박스 이름은 "원격 접속 허용")이고 **페어링 링크 복사**가 생겼다. **다른 PC에 접속**에 그 링크를 붙여 넣거나 접속 주소와 코드를 입력하면 등록된다. 호스트 설정이 보여 주는 `http://100.x.y.z:47821/mobile/`을 그대로 붙여 넣어도 된다.
- **원격 창** — 사이드바 아래 **원격 PC**에서 등록한 PC를 누르면 그 PC의 세션 화면이 별도 창으로 열린다. 왼쪽에 세션 목록, 오른쪽에 터미널이 나란히 있고 키보드 입력이 바로 터미널로 간다. 화면은 **호스트 PC가 자기 버전의 것을 서빙**하므로 두 PC의 앱 버전이 달라도 어긋나지 않는다.
  - 터미널은 **창 크기에 맞춰진다.** 호스트 PC에서 그 세션에 입력하거나 패인 크기를 바꾸면 호스트가 크기를 되찾고 원격 창은 맞춤을 멈춘다. **다시 맞추기**를 누르거나 창 크기를 바꾸면 다시 맞춘다. 호스트 크기 그대로 보려면 **호스트 크기 유지**.
  - 복사는 Ctrl+Shift+C(선택 영역이 있으면 Ctrl+C도), 붙여넣기는 Ctrl+V.
  - 넓은 화면의 PC 브라우저로 `…/mobile/`을 열어도 같은 화면이 나온다.
- **세션 관리** (원격 창과 폰 공통) — 목록의 **새 세션**으로 호스트 PC의 폴더와 에이전트를 골라 띄운다. 세션 화면 머리줄의 **중지**·**재시작**·**삭제**로 정리하고, 삭제는 한 번 더 묻는다. 호스트 PC 화면의 선택과 배치는 바뀌지 않는다. 호스트가 거절하면(이미 끝난 세션, 진행 중인 PR 리뷰 세션 등) 이유가 화면 아래에 뜬다.
- **알림** — 등록한 PC의 세션이 입력·승인을 기다리거나 끝나면 이 PC에 알림이 뜨고, 누르면 그 세션이 원격 창으로 열린다. 이 PC의 알림 설정(상태별 토글, 방해 금지, 1시간 끄기)을 따르고, 설정 ▸ 원격에서 PC마다 끌 수 있다. 그 PC의 원격 창을 보고 있는 동안에는 뜨지 않는다. 사이드바의 호스트 행에는 연결 상태와 기다리는 세션 수가 보인다. 앱을 켤 때 이미 기다리던 세션에 대해서는 알림을 내지 않고 수로만 보인다.

## 보안

- 원격 창은 다른 PC가 서빙한 페이지를 띄우므로 샌드박스에 가둔다: 호스트별로 분리된 세션, 그 호스트 출처 밖으로의 이동·팝업·권한 요청·다운로드 차단. 기기 토큰은 **main이 요청한 프레임의 출처를 확인한 뒤** 그 호스트의 메인 프레임에만 준다.
- 이 PC의 터미널 출력과 IPC는 메인 창에만 간다. 원격 창에 포커스가 있어도 이 PC 세션의 알림은 정상으로 뜬다.
- 호스트 토큰은 OS 자격 증명 저장소(safeStorage)로 암호화해 `userData/remote-hosts.json`에 둔다. 주소는 Tailscale 대역(100.64.0.0/10)만 등록할 수 있다.
- 이 PC의 클립보드를 원격 페이지가 읽는 길은 없다. 붙여넣기는 사용자의 키 입력으로만 일어난다.
- 호스트가 이 PC를 연결 해제하면 원격 창과 상태 연결이 끊기고 "다시 페어링 필요"로 남는다.

## 알아둘 것

- **호스트 PC도 이 버전으로 올려야** 넓은 화면·창 크기 맞춤·세션 관리·페어링 링크 복사가 나온다. 호스트가 v1.35.x면 원격 창이 폰 화면 그대로 보인다. 접속과 알림은 v1.35.x의 프로토콜만 쓰도록 만들었지만, 구버전 호스트와의 조합은 아직 실기로 확인하지 못했다.
- Linux에서 다른 PC를 등록하려면 OS 키링(gnome-keyring 등)이 있어야 한다. 없으면 토큰을 평문으로 저장하지 않고 등록을 거부한다.
- 알림은 이 PC의 앱이 켜져 있을 때(트레이 포함)만 온다. 폰 잠금 중 알림은 아직 없다(모바일 P3).
- 여러 PC의 세션을 한 목록으로 합치거나 메인 창 그리드에 원격 세션을 섞는 것은 하지 않는다. 원격에서 워크트리를 골라 새 세션을 만드는 것도 아직 없다.
- Android 앱 안의 안내 문구("설정 ▸ 모바일")는 다음 셸 릴리스에서 "원격"으로 고친다.
- "삭제됨"을 알리는 내부 이벤트가 생겨, 폴더를 지우거나 워크트리를 정리할 때도 세션 목록이 같은 길로 갱신된다.

## 검증

- 전체 Vitest(162개 파일, 1,786개 테스트) 및 TypeScript 통과
- Electron E2E 전체 통과(26개) — 앱 하나가 자기 자신을 원격 PC로 등록해 확인하는 e2e 추가: 등록(Tailscale 밖 주소 거부) → 원격 창 → 키 입력 → 호스트가 크기를 되찾으면 멈춤 → 붙여넣기·복사 → 새 세션 → 중지 → 재시작(원격·호스트 양쪽에서) → 삭제 → 연결 해제. 기존 모바일 e2e는 수정 없이 통과
- 단계마다 독립 코드 리뷰 1회. 리뷰에서 나온 결함(호스트와 번갈아 크기를 바꾸던 문제, 삭제 직후 거짓 오류, 알림을 눌러도 세션이 안 열릴 수 있던 문제 등)은 재현 테스트를 먼저 쓰고 고쳤다
- 실제 두 PC(Tailscale)에서의 이어받기와 알림은 이 릴리스로 수동 확인 예정
