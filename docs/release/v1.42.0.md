# v1.42.0 — 그리드 페이지 탭

세션이 레이아웃 칸 수보다 많아 그리드가 여러 페이지로 나뉠 때, 다른 페이지에 무엇이 있는지 보이고 한 번에 넘어간다.

## 바뀐 것

- **페이지 탭**
  - 헤더의 작은 `‹ 1/3 ›` 자리에 페이지마다 탭이 하나씩 생긴다. 탭에는 그 페이지에 있는 패인 이름이 적힌다(`1 claude · codex`).
  - 탭을 누르면 그 페이지로 바로 간다. 지금 보는 페이지의 탭은 강조색 테두리를 두른다.
  - 그 페이지에 입력·승인을 기다리는 세션이 있으면 탭에 사이드바와 같은 색의 점이 찍힌다. 승인 대기가 우선한다.
  - 헤더가 좁아지면 이름이 말줄임으로 줄어든다. 헤더 폭이 620px 이하가 되면 번호와 점만 남는다. 이때 이름은 마우스를 올리면 보인다. 이렇게 줄어들어도 오른쪽의 에이전트 런처는 밀려나지 않는다.
- **페이지 단축키**: `Ctrl+PageUp`/`Ctrl+PageDown`으로 이전·다음 페이지로 간다. 넘어간 페이지의 첫 세션이 키보드를 받는다. 넘길 페이지가 없으면 키를 가로채지 않고 터미널로 보낸다. 설정 › 단축키에서 바꿀 수 있다.
- **`Ctrl+Tab`이 페이지를 넘는다**: 예전에는 지금 페이지 안에서만 돌았다. 이제 페이지 끝에서 이웃 페이지로 넘어가므로, 페이지가 나뉘어 있어도 키보드만으로 모든 세션에 닿는다.

폰 앱(0.2.0)은 바뀌지 않았다.
