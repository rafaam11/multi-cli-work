# v1.62.0 — 상단 메뉴 정리와 명령 하나로 통합

상단 메뉴를 6개에서 4개로 줄였습니다. 메뉴, 명령 팔레트(Ctrl+Shift+P), 단축키 설정이 각자 따로 갖고 있던 명령 목록을 하나로 합쳤습니다. 그래서 메뉴에 있는 명령은 팔레트에서 단축키와 함께 찾을 수 있습니다. 거꾸로 단축키나 팔레트로만 쓸 수 있던 기능도 메뉴에 올라왔습니다.

- **메뉴 4개 (파일·보기·세션·도움말)**
  - 편집 메뉴는 없앴습니다. 복사·붙여넣기·모두 선택·찾기·화면 지우기는 **터미널을 우클릭**하면 나옵니다.
  - 도구 메뉴는 **세션 › 에이전트 ▸**로 들어갔습니다(Claude Code 업데이트, Codex 업데이트, 에이전트 추가).
  - 다시 로드와 개발자 도구는 **도움말 › 문제 해결 ▸**로 옮겼습니다.
  - 확대·축소·원래 크기는 **보기 › 화면 배율 ▸**에 모였습니다.
- **새로 메뉴에 올라온 기능**:
  - 보기: 명령 팔레트, 홈 대시보드, 폴더 기록, 패인 확대/해제, 작업 영역 새로고침
  - 세션: 다음 세션·이전 세션·다음 대기 세션, 프롬프트 라이브러리, 보류 메시지 관리, 알림 1시간 끄기/다시 켜기
  - 도움말: 단축키 보기
  - 알림 끄기는 트레이와 설정 › 알림과 같은 값을 씁니다. 꺼져 있으면 메뉴에 "알림 다시 켜기 (HH:MM까지 꺼짐)"이 보입니다.
- **명령 팔레트(Ctrl+Shift+P)**
  - 지금 실행할 수 있는 명령을 모두 보여 줍니다. "세션: 중지"처럼 분류를 붙이고 오른쪽에 단축키를 표시합니다.
  - 지금 쓸 수 없는 명령은 목록에서 빠집니다.
  - 단축키를 바꾸면 메뉴와 팔레트 표시가 함께 바뀝니다. 설정 › 단축키에서는 기본 단축키가 없던 명령(세션 중지 등)에도 키를 지정할 수 있습니다.
- **빠른 열기(Ctrl+P)는 이동 전용**: 세션·작업공간·폴더·업무 프로젝트만 찾습니다. 명령은 Ctrl+Shift+P나 '명령' 칩에서 찾습니다. 커맨드센터를 누르면 항상 빠른 열기로 열립니다.
- **세션 메뉴의 대상**: 재개·새로고침·중지·제거는 **포커스된 패인의 세션**에 작동합니다. 패인 헤더의 버튼과 같은 대상입니다. 전에는 작업공간 화면에 들어가거나 문서 패인에 포커스를 주면, 메뉴가 폴더에서 마지막으로 고른 다른 세션에 작동할 수 있었습니다. 새 세션은 헤더의 실행 버튼과 같은 곳에서 시작합니다. 폴더 화면에서는 그 폴더·워크트리에서, 작업공간 화면에서는 포커스된 패인의 폴더·워크트리에서 시작합니다.
- **중복 정리**:
  - 워크스페이스 헤더의 세션 제거(🗑)와 폴더 다시 연결(📁) 버튼을 뺐습니다. 제거는 모든 패인 헤더에 있습니다. 다시 연결은 폴더가 사라졌을 때 뜨는 안내 줄과 파일 메뉴, 폴더 우클릭에 있습니다.
  - 사이드바 아래의 업데이트 배지는 확인 중·다운로드 중·재시작 필요·실패일 때만 보입니다. 메뉴에서 업데이트를 확인했는데 최신이면 알림으로 알려 줍니다.
- **이름 통일**: 같은 기능은 메뉴와 사이드바에서 같은 이름을 씁니다. 폴더 열기, 업무 프로젝트 만들기, 작업 영역 새로고침(사이드바의 옛 "목록 새로고침")입니다.

**호환성**
- 저장 형식과 IPC는 바뀌지 않았습니다.
- 기존 명령 id와 기본 단축키는 그대로라서, 설정에서 바꿔 둔 단축키는 계속 동작합니다.
- 바뀐 것은 다음과 같습니다.
  - "모두 선택"에 붙어 있던 Ctrl+A 표기를 지웠습니다. Ctrl+A는 원래부터 셸로 전달됐습니다(줄 맨 앞으로 이동).
  - 접근성 이름으로 UI 자동화를 하는 스크립트가 있다면 맞춰야 합니다. "목록 새로고침"은 "작업 영역 새로고침", "프로젝트 만들기"는 "업무 프로젝트 만들기", 메뉴의 "폴더 추가"는 "폴더 열기"가 됐습니다.

**한계**
- 터미널 우클릭은 TUI가 마우스 모드여도 앱 메뉴를 엽니다. 우클릭을 직접 쓰는 터미널 프로그램에는 우클릭이 전달되지 않습니다.
- 패인 방향 이동, 페이지 넘김, 슬롯 1~9 포커스는 메뉴에 넣지 않았습니다. 키와 명령 팔레트로 씁니다.

**검증**
- Windows에서 타입 검사와 Vitest 251개 파일·2,574개 테스트를 통과했습니다.
- desktop Electron E2E 67개 중 66개가 통과했습니다. 나머지 1개(codex 워크트리 감지)는 이 변경과 무관한 부하 플레이크로, 단독으로 다시 돌려 통과했습니다. 터미널 우클릭 메뉴 스모크 시나리오는 새로 추가했습니다.
- 격리 인스턴스에서 메뉴·하위 메뉴·명령 팔레트를 화면으로 확인했습니다. 터미널에서 드래그하거나 모두 선택한 내용이 우클릭 뒤에도 남고, 복사하면 클립보드에 들어가는 것도 확인했습니다.
- main CI의 Ubuntu 테스트와 Windows 2022·Ubuntu 22.04 desktop Electron E2E, Android 셸 빌드를 태그 전에 확인합니다. 패키징은 릴리스 CI에서 수행합니다.
