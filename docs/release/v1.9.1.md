# v1.9.1 — 터미널 링크 열기와 탭 복귀 스크롤백 복구

## 변경 사항

- 다른 탭에 갔다가 세션으로 돌아올 때 대화 내용에 빈 줄이 잔뜩 삽입되던 문제 수정. 새로 만든 터미널이 xterm 기본 80×24 크기인 상태에서 replay를 기록해, PTY가 넓은 폭으로 출력한 줄이 다시 접히던 것이 원인이었다
- 이제 replay를 받기 전에 pane의 실제 크기로 맞추고 PTY에도 같은 크기를 먼저 보고한다
- 터미널에서 링크를 클릭해도 외부 브라우저가 열리지 않던 문제 수정. xterm.js 기본 핸들러의 `window.open` 확인창 대신 메인 프로세스의 `shell.openExternal`로 넘겨 OS 기본 브라우저에서 바로 연다
- 링크 열기가 실패하면 세션 오류 메시지로 표시된다
- http/https 링크만 열리는 기존 제약과 렌더러 팝업 차단 정책은 그대로 유지

## 검증

- replay가 pane의 실제 크기로 맞춰진 뒤에 기록되는지, PTY 크기 보고가 attach보다 먼저인지 확인하는 회귀 테스트 추가
- 터미널 링크 클릭이 `shell.openExternal`로 전달되고 차단되는 `window.open`을 쓰지 않는지 확인하는 회귀 테스트 추가

- TypeScript typecheck 및 프로덕션 빌드 통과
- Electron E2E smoke 6개 시나리오 통과 (전체 E2E는 릴리스 워크플로가 Windows 2022·Ubuntu 22.04에서 수행)
