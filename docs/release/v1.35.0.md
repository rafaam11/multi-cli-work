# v1.35.0 — 모바일(Android) 컴패니언

외출 중에도 PC에서 돌고 있는 claude·codex 세션을 폰에서 보고, 입력하고, 승인한다. PC와 폰은 Tailscale로 묶여 있다는 전제이고(sunshine-moonlight처럼), 공인 인터넷에는 아무것도 열지 않는다. 이 버전부터 데스크톱 설치본이 Android 앱(APK)을 동봉해 직접 나눠준다 — 폰에서 APK를 손으로 받는 건 처음 한 번뿐이다.

설계: [`docs/superpowers/specs/2026-09-30-mobile-companion-design.md`](../superpowers/specs/2026-09-30-mobile-companion-design.md) · 설치·페어링·업데이트 안내: [설치 문서의 모바일 절](../installation.md#모바일android-컴패니언)

## 새 기능

- **설정 › 모바일** — **모바일 연결 켜기**(기본 꺼짐)와 포트(기본 47821). 켜도 서버는 **Tailscale 인터페이스의 100.64.0.0/10 주소에만** 열리고, Tailscale이 앱보다 늦게 켜지면 30초마다 다시 시도한다. **기기 추가**는 5분짜리 일회용 코드로 **페어링 QR**과 처음 설치용 **앱 설치 QR**을 띄운다. 페어링된 기기 목록에서 **연결 해제**하면 그 기기의 열린 연결이 곧바로 끊긴다.
- **Android 앱 "멀티 터미널" v0.1.0** (Android 12 이상, 권장 14 이상)
  - 여러 PC를 등록해 두고 골라 접속한다. 앱 안 **QR로 PC 추가**로 찍거나, 폰 카메라로 페어링 QR(`mcw://pair` 딥링크)을 찍으면 앱이 열리며 확인 창이 뜬다. 같은 PC를 다시 페어링하면 중복 없이 갱신된다.
  - 세션 화면은 **PC가 자기 버전의 모바일 UI를 서빙**한다 — 데스크톱이 업데이트되면 폰 화면도 따라 바뀐다. 세션 목록(폴더별·상태 배지), 실제 터미널, 여러 줄 입력창, 빠른 키(`Esc` `Tab` `↑` `↓` `Enter` `^C` `1` `2` `3` `/`), **📱 폰 크기로**(기본은 PC 열 수 유지 — PC에서 그 세션에 입력하거나 패인 크기를 바꾸면 PC가 크기를 되찾는다).
  - **자가 업데이트** — 등록된 PC 중 가장 새 셸을 동봉한 PC에서 APK를 받아, **sha256과 서명 인증서가 설치본과 같을 때만** 설치한다. 처음 한 번 "이 출처의 앱 설치 허용"이 필요하다.
- 폰 브라우저만으로도 쓸 수 있다 — `http://<Tailscale IP>:47821/mobile/`에서 페어링 코드를 입력한다.

## 보안

- 기기 토큰은 256bit이고 PC에는 sha256 해시만 저장한다(`userData/remote-devices.json`). 토큰은 WebSocket 첫 메시지로만 오가며 URL에 싣지 않는다. 폰에서는 Android Keystore AES-GCM 키로 봉인한다.
- 페어링 코드는 5분·1회용이고, IP당 1분 5회 실패면 거절, 한 코드에 10회 실패면 폐기한다. 해제된 기기는 소켓이 닫히기 전에도 입력이 막힌다.
- 앱의 WebView는 등록된 PC 주소 밖으로 이동하지 않고, 페어링 QR은 Tailscale 대역 주소만 받는다. 응답한 PC가 QR의 PC와 다르면 저장하지 않는다.
- 전송 암호화는 Tailscale(WireGuard)이 맡는다.

## 알아둘 것

- 로컬 `npm run dist:*`는 `npm run mobile:prepare`로 `build/mobile`을 먼저 준비하지 않으면 앱을 동봉하지 않는다. 릴리스 CI는 항상 동봉한다.
- 알림(폰 잠금 중 입력 대기 알림)은 다음 단계(P3)다.
- Android 앱 서명 키는 레포 밖에 있다. 인증서 SHA-256 `f313f9a57702bff47c5e2b6fa10b032e3f434513004ca14ca8834457ffb844e9`.

## 검증

- 전체 Vitest(144개 파일, 1,619개 테스트) 및 TypeScript 통과
- Electron E2E 전체 통과(25개) — 폰 역할 창으로 페어링 → 세션 목록 → 입력 → 해제까지 확인하는 모바일 e2e 추가
- Android 단위 테스트(페어링 URI·셸 릴리스·sha256·호스트 HTTP·호스트 저장소·WebView origin·업데이트 판정) 통과, 서명된 release 빌드 확인
- 실기기(설치·QR/딥링크 페어링·회전·해제·업데이트 한 사이클)는 이 릴리스로 수동 확인 예정
