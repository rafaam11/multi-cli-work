# v1.11.0 — 업무 프로젝트 노션 링크 복수 등록

## 변경 사항

- 업무 프로젝트의 노션 URL이 라벨 붙은 링크 목록으로 확장 — 채널 페이지와 연차별(1차년도·2차년도…) 프로젝트 페이지를 각각 등록
- 상세 페이지에서 링크 행 추가/삭제/열기, 라벨·URL 편집 (blur 시 자동 저장, 빈 URL 행은 저장 시 제외)
- 세션 브리프에 모든 링크가 `- 노션(라벨): URL` 형태로 나열되어 Claude가 특정 연차 페이지를 정확히 참조 가능
- 기존 단일 notionUrl은 읽기 시 "노션" 라벨 링크로 자동 승격, 첫 저장 시 새 형식으로 자가 치유 (데이터 손실 없음)
- e2e 테스트 하네스가 `work-projects.json`을 다른 레지스트리처럼 격리 — 테스트가 사용자 실데이터를 읽거나 쓸 위험 제거

## 릴리스 자산
