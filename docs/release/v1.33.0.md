# v1.33.0 — 가장자리 정리

v1.32.0에 이어 2026-09-28 탐색의 나머지 버그를 고친다. 쓰는 흐름을 막던 것은 아니지만, 거짓말하는 설정·영어 원문 오류·앱과 어긋난 대화상자·쌓이기만 하는 잔재가 없어진다.

- **적용되지 않는 언어 선택을 숨긴다.** 설정 › 일반의 한국어/English는 v1.23.0부터 저장만 되고 어디에도 쓰이지 않았다. i18n이 붙을 때 돌아온다. 저장된 값은 `settings.json`에 그대로 남아 다운그레이드해도 잃지 않는다.
- **오류 배너가 한국어로, 필요한 말만 한다.** 레지스트리가 깨져 백업으로 내려앉을 때(`폴더 목록(projects.json) 파일이 손상돼 백업을 읽기 전용으로 씁니다 — …`), `agents.json`을 못 읽을 때, 목록에서 사라진 에이전트의 세션을 재개할 때의 문구가 한국어가 됐다. 배너 대부분에 붙던 Electron 접두어(`Error invoking remote method '…': Error:`)는 모든 화면에서 걷어 낸다.
- **네이티브 확인 창이 없어졌다.** PR 리뷰 정리와 업무 프로젝트 삭제가 `window.confirm`으로 물어 렌더러를 멈추고 앱의 다른 대화상자와 모양이 달랐다. 앱의 확인 대화상자로 바꿨다 — Esc·취소·바깥 클릭은 모두 "아니오"다.
- **사라진 폴더에서는 시작 버튼이 꺼진다.** 홈 대시보드의 빠른 실행이 사라진 폴더에도 버튼을 켜 두어, 눌러도 아무 일이 없었다. 빈 슬롯의 최근 폴더 메뉴와 같은 판정으로 끄고 툴팁에 이유를 적는다.
- **사라진 폴더를 탐색기가 조회하지 않는다.** 폴더를 선택할 때마다 main 로그에 ENOENT 스택이 남았다. 이제 탐색기는 조회를 건너뛰고 "폴더를 찾을 수 없습니다 — 다시 연결하면 파일을 볼 수 있습니다"라고 말한다.
- **잔재를 치운다.** 앱을 시작할 때 쓰다 죽은 `state.json.*.tmp`(1분 초과)를 지우고, 목록에서 빠진 폴더·워크트리의 저장된 그리드를 복원하면서 버리며, 등록되지 않은 폴더의 세션 브리프(`project-briefs/*.md`)를 지운다. 한 설치본에는 살아 있는 대상 12개에 그리드 26개가 쌓여 있었다.
- **설정의 워크스페이스 루트 행**에서 긴 경로가 `제거` 버튼을 한 글자 폭으로 짓누르던 레이아웃을 고쳤다.
- **문서** — README에 노션 연동(링크 제목 조회, 암호화된 토큰 파일, `api.notion.com` 통신)과 설정 대화상자 절을 더했다. `docs/local-data.md`의 userData 폴더 이름을 실제 이름(`multi-cli-work`)으로 바로잡고, `docs/development.md`에 Windows `npm ci`의 node-pty 재빌드 실패가 무해하다는 안내를 넣었다.
