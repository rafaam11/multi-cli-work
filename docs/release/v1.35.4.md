# v1.35.4 — 폰에서 claude 대화 내역 스크롤

v1.35.2의 터치 스크롤이 claude 세션에서는 듣지 않던 문제를 고친다. (v1.35.3 태그는 Windows CI의 e2e 판정 문제로 릴리스하지 않았고, 같은 수정을 이 버전으로 낸다.) 모바일 화면은 PC가 서빙하므로 **PC만 업데이트하면 되고, 폰 앱(0.1.1)은 그대로다.**

## 버그 수정

- **폰에서 claude 세션이 스크롤되지 않았다.** claude는 전체 화면(alternate screen)으로 그리고 마우스 추적을 켠다. 이때 xterm에는 스크롤백이 없고, claude가 휠 입력을 받아 자기 대화 내역을 스스로 스크롤한다. v1.35.2는 xterm 스크롤백만 넘겨서, "📱 폰 크기로"를 켜면 아예 안 움직이고 끄면 PC 화면 한 장만 움직였다. 이제 전체 화면 세션에서는 세로 드래그를 마우스 휠 입력으로 바꿔 xterm에 넘긴다 — xterm이 앱이 켠 방식(마우스 추적이면 SGR 휠, 아니면 화살표 키)대로 보내므로 PC에서 휠을 굴린 것과 같다. PowerShell·bash처럼 스크롤백이 쌓이는 세션은 v1.35.2처럼 스크롤백을 넘긴다.

## 검증

- 전체 Vitest(145개 파일, 1,628개 테스트) 및 TypeScript 통과
- 모바일 e2e에 "전체 화면 + 마우스 추적을 켠 앱에서 드래그 → 폰이 SGR 휠(`ESC[<64;…`)을 보낸다"를 추가 — 수정을 빼면 실패, 넣으면 통과. Linux에서만 돈다: Windows ConPTY는 버전에 따라 전체 화면 전환이나 테스트 앱(raw 모드 node)의 마우스 모드 요청을 xterm에 넘기지 않아(Server 2022 러너) 판정이 흔들린다. claude는 VT 입력을 켜서 Windows 11에서도 둘 다 넘어온다.
