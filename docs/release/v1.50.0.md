# v1.50.0 — 드라이브 폴더 템플릿과 문서 루트 종류 선택

업무 프로젝트의 문서 폴더를 만들 때 쓰는 하위 폴더 구성을 템플릿으로 관리하고, 문서 루트를 Google Drive 밖(OneDrive·NAS·로컬 디스크 등)으로 두는 사용자도 맞는 이름과 아이콘을 쓰도록 했다.

- **폴더 템플릿**: 설정에서 템플릿(이름 + `/`로 나눈 하위 폴더 경로)을 만들고 고치며, 구분마다 기본 템플릿을 고른다. 프로젝트 생성 대화상자와 문서 카드에서 폴더를 만들 때 템플릿을 고르거나 비워 둘 수 있다. 기본값은 "최소"와 "과제형" 두 벌이며, 템플릿은 프로필로 PC 간에 옮겨진다.
- **문서 루트 종류**: 설정 › PC · 프로필의 "문서" 루트 아래에서 종류를 아이콘 목록(Google Drive·OneDrive·Dropbox·iCloud Drive·Teams/SharePoint·NAS·로컬 디스크·폴더·클라우드)에서 고른다. "자동"이면 경로로 짐작한다. 카드 제목, 생성 대화상자, 사이드바 아이콘, 오류 문구, 세션 브리프, 새 폴더의 CLAUDE.md가 고른 종류의 이름을 따른다. 로컬 디스크·폴더 종류는 브리프에서 동기화 안내를 빼고 git 금지 문장만 남긴다.
- 문서 루트 종류는 경로와 같이 PC별 설정이라 프로필 내보내기에서 빠진다.

전체 단위 테스트 2,202개와 타입 검사를 통과했다. 기존 설정은 그대로 읽히며(종류가 없으면 자동), 폰 앱은 바뀌지 않았다.
