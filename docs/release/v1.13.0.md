# v1.13.0 — 멀티세션 그리드와 2레이어 사이드바

## 변경 사항

- **폴더를 누르면 그 폴더의 세션이 한 화면에 함께 뜬다.** 이전에는 상세 페이지를 거쳐 세션을 하나씩 골라야 했고 동시에 볼 수 있는 터미널은 2개(화면 분할)까지였다. 이제 폴더 클릭이 곧 터미널 화면이며, 최근 활동순으로 최대 6개까지 자동 배치된다 — 1개는 단일, 2개는 1×2, 3~4개는 2×2, 5~6개는 2×3
- 세션이 6개를 넘으면 패인 헤더의 **"+N" 버튼**에서 화면 밖 세션을 골라 그 자리와 교체한다. 교체해도 세션은 계속 살아 있고 스크롤백도 그대로다
- **세션 조작이 패인 헤더로 옮겨졌다.** 각 패인이 자기 세션의 상태 점·이름·재개·새로고침·중지·패인 닫기를 갖는다. 이름은 제목 더블클릭으로 바꾸고, 우클릭 메뉴에서 제공자 제목으로 되돌리거나 세션을 제거한다. "패인 닫기"는 화면에서만 내리며 세션을 종료하지 않는다
- **사이드바가 2레이어(업무 프로젝트 → 폴더)로 정리됐다.** 세션 행이 사라진 자리에는 폴더 행의 읽지 않음 배지가 남아, 화면 밖 세션의 알림만 모아 보여준다. 업무 프로젝트 행이 폴더 행보다 높아지고 폴더 레이어 들여쓰기가 커져 계층 구분이 분명해졌다
- 상세 페이지는 없어지지 않았고 진입 경로만 바뀌었다 — 터미널 화면 헤더의 **"폴더 상세"** 버튼
- 헤더의 🔧 도구 메뉴를 없앴다. CLI 업데이트 확인과 에이전트 추가는 타이틀바 도구 메뉴와 홈 대시보드 카드로 일원화된다. 타이틀바 세션 메뉴의 "화면 분할"도 그리드로 대체돼 사라졌다
- **알림·읽지 않음 판정이 그리드 전체를 본다.** 화면에 떠 있는 패인 중 하나라도 그 세션이면 알림을 띄우지 않는다
- 중단된 세션의 자동 재개는 **동시 2개까지**만 실행하고 나머지는 큐에서 기다린다. 6패인이 한꺼번에 붙을 때 재개가 몰리는 것을 막는다
- 이전 버전의 화면 분할 상태(`splitSessionId`)는 상태 파일을 읽을 때 새 `visibleSessionIds` 배열로 자동 변환된다. 재시작하면 실제로 남아 있는 세션만 그리드에 복원된다
