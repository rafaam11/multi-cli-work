# v1.39.0 — 패인 확대, 대기 세션 점프, 파일 경로 링크, 진행 표시

Ghostty·cmux·Orca를 살펴보고 가져온 터미널 쪽 기능 네 가지다. 여러 에이전트를 한 화면에 띄워 둔 채 오가는 일이 빨라진다.

## 바뀐 것

- **패인 확대 (`Ctrl+Shift+Enter`)**
  - 지금 패인이 그리드 전체를 잠시 차지한다. 패인 머리줄의 ⤢ 버튼으로도 된다.
  - 다른 패인은 숨을 뿐 터미널 연결은 그대로라, 돌아오면 그대로 있다. 숨은 동안에는 PTY 크기도 바꾸지 않는다.
  - 확대 중에 `Ctrl+Tab`이나 `Ctrl+숫자`로 옮기면 확대가 그 패인으로 따라간다.
  - 확대 상태는 저장하지 않는다. 배치나 폴더가 바뀌면 풀린다.
- **방향으로 패인 이동 (`Ctrl+Alt+방향키`)**
  - 그리드에서 그 방향의 이웃 패인으로 포커스를 옮긴다. 빈 슬롯은 건너뛰고, 확대 중이면 확대를 먼저 푼다.
  - 일부 Intel 그래픽 드라이버의 화면 회전 키와 겹친다. 그런 PC라면 설정 › 단축키에서 바꾼다.
- **다음 대기 세션 (`Ctrl+Shift+U`, 타이틀바 표시 클릭)**
  - 입력·승인을 기다리는 세션으로 간다. 고르는 순서는 승인 대기 먼저, 아직 안 본 것 먼저, 오래 기다린 것 먼저다.
  - 다시 누르면 다음 세션으로 넘어간다. 다른 폴더나 다른 페이지에 있으면 화면에 데려온다.
  - 타이틀바의 `!`·`●` 표시도 이제 누를 수 있다.
- **파일 경로 링크 (`Ctrl+클릭`)**
  - 에이전트가 출력한 경로를 Ctrl+클릭하면 열린다. `src/app.ts:42:7`, `index.ts(12,3)`, `./README.md`, 절대 경로를 알아본다.
  - 링크가 되는 것은 그 세션의 폴더(worktree) 안에 실제로 있는 파일뿐이다. 확인은 main이 파일 탐색기와 같은 루트 검사로 한다.
  - 여는 방식은 설정 › 파일의 확장자별 지정을 따른다. VS Code로 열면 그 줄·열에서 열리고, 앱 안에서 열면 그 줄이 선택된다. Markdown은 편집 화면으로 바뀐다.
  - 그냥 클릭은 지금처럼 텍스트 선택이다.
- **진행 표시**
  - 세션이 ConEmu `OSC 9;4`로 진행률을 알리면 패인 머리줄 밑 2px 선이 그만큼 찬다. 오류는 빨강, 멈춤은 호박색이다.
  - 알리는 것이 없어도 작업 중인 세션에는 옅은 빛이 흐른다. 그리드를 훑어보면 일하는 패인과 기다리는 패인이 갈린다.
  - 진행률은 작업표시줄 아이콘에도 뜬다. 여러 세션이 알리면 가장 뒤처진 것을 따른다(설정 › 일반에서 끈다).
  - `prefers-reduced-motion`이면 움직이지 않는 선으로 보인다.

## 알아둘 것

- **Claude Code의 진행 신호는 쓰지 않는다**
  - Claude Code는 ConEmu·Ghostty·iTerm2로 판별되는 터미널에서만 `OSC 9;4`를 낸다.
  - 환경 변수(`ConEmuANSI`)를 꾸미면 켤 수는 있다. 하지만 Claude가 내는 것은 "작업 중/끝" 두 가지뿐이라 hook으로 이미 아는 상태와 같아서 하지 않았다.
  - Claude 세션의 작업 중 표시는 hook 상태로 그린다.
- 작업 중 상태에 따른 흐르는 빛은 패인 머리줄에만 있다. 작업표시줄은 세션이 진행률을 직접 알릴 때만 움직인다.

## 검증

- 단위 테스트(전체 178개 파일 / 1,904개)를 통과했다. 새로 붙인 것:
  - OSC 9;4 해석기(청크 분할, BEL/ST)와 세션별 추적, 작업표시줄 합산
  - 이웃 슬롯 계산, 숨은 패인 resize 생략
  - 대기 세션 순서와 순환
  - 경로 파서(Windows·POSIX·tsc 형식, 한글 2셀 폭, 줄바꿈된 경로)와 링크 provider(캐시, Ctrl 없는 클릭 무시)
  - main 경로 해석(루트 밖·폴더·없는 파일 거절), VS Code `--goto` 인자, 줄 선택
- TypeScript 검사와 프로덕션 빌드를 통과했다.
- Electron E2E `desktop.spec.ts` 23개를 통과했다. 실제 PTY로 확인한 장면:
  - PowerShell이 `9;4;1;40`을 내면 진행선이 40%가 되고, 지우면 사라진다
  - 확대해도 다른 패인의 xterm이 유지되고, 확대가 `Ctrl+Tab`을 따라가며, 방향키로 풀린다
  - 출력된 `readme.md:1`을 Ctrl+클릭하면 파일이 열리고 1번 줄이 선택된다
