# v1.52.0 — 원격 창이 호스트 화면을 따라 그린다

넓은 화면의 원격 창이 호스트 메인 창의 그리드를 그대로 보여 준다. 어느 쪽에서 바꾸든 다른 쪽이 따라온다. 사이드바의 프로젝트 영역도 원격에 생겼다.

- **호스트 화면 미러링**: 원격 창이 호스트와 같은 레이아웃, 칸 배치, 페이지, 포커스로 그린다. 원격에서 레이아웃을 고르거나 열을 나누고 합치거나 페이지를 넘기면 호스트 화면이 바뀐다. 칸을 닫거나 머리줄을 끌어 다른 칸으로 옮겨도 마찬가지다. 호스트에서 바꾼 것은 원격에 바로 반영된다. 호스트에 열린 문서 칸은 자리표시로 보인다.
- **프로젝트 트리**: 세션 목록 아래에 업무 프로젝트 → 폴더 → 메인/worktree → 세션 트리가 생겼다. 메인 창 사이드바와 같은 순서다. 폴더나 worktree 행을 누르면 호스트가 그 그리드로 옮겨 간다. 펼침 상태는 기기마다 기억하고, 모두/접기/작업중 버튼이 있다.
- **원격에서 새 세션**: 트리의 폴더·worktree 행 끝 "+"를 누르면 그 위치를 골라 둔 새 세션 폼이 열린다. 만든 세션은 호스트 그리드에 열린다.
- **세션 이름 변경**: 칸 머리줄의 이름을 두 번 눌러 바꾼다. 바꾼 이름은 호스트와 모든 원격 화면에 반영된다.

폰처럼 좁은 화면은 호스트 화면을 바꾸지 않는다. 트리는 펼쳐 보기만 하고, 세션은 그 화면에서만 연다. 원격 화면은 호스트가 제공하므로 이 PC만 업데이트하면 된다.
