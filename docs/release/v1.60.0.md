# v1.60.0 — GitHub풍 라이트 테마와 페이지 탭 이름 정리

라이트 테마를 다크 테마를 뒤집은 모양이 아니라 GitHub·VS Code의 라이트 테마를 따르도록 새로 잡았습니다. 메인 창에서 세션이 레이아웃보다 많아 페이지로 나뉠 때 작업공간 이름 옆에 붙는 페이지 탭도 읽기 쉽게 고쳤습니다.

- **라이트 테마 색**: 녹색기가 돌던 회색 대신 중립적인 차가운 회색을 씁니다. 패인과 편집기는 흰색, 사이드바와 헤더는 `#f6f8fa`, 테두리와 글자색은 Primer 값이고, 선택·포커스·활성 탭·드롭 대상·링크·기본 동작에 쓰는 강조색은 파랑(`#0969da`)입니다. 청록은 "작업 중인 세션"의 색으로만 남고, 다크 테마는 청록 강조색을 그대로 씁니다.
- **라이트 테마 강도**: 배경 물결·광택·그림자의 강도를 테마가 가진 값으로 곱하도록 바꿨습니다. 라이트 테마는 물결을 다크 대비 0.6으로 줄이고 광택을 없애고 그림자를 옅은 회색으로 바꿔, 짙은 덩어리로 보이던 색면이 옅어집니다. 선택된 업무 프로젝트의 빨강·분홍 테두리도 같은 비율로 조용해지고, 분류·태그 색은 상태 색보다 한 단계 낮춥니다. 다크 테마의 값은 예전과 같아 보이는 모습이 바뀌지 않습니다.
- **라이트 터미널·편집기·그래프**: 터미널, Monaco diff, git 그래프 레인이 흰 배경용 Primer 팔레트를 따로 갖습니다. 24비트 색으로 칠하는 CLI가 어두운 배경을 가정해 보낸 흰 글자나 옅은 회색은, 라이트 테마에서 셀 배경 대비 4.5:1이 안 되면 xterm이 자동으로 어둡게 보정합니다. 다크 테마는 보낸 색을 그대로 씁니다. 테마를 바꿔도 터미널을 다시 만들지 않아 스크롤백이 유지되며, 라이트 패인의 마지막 줄 아래에 검은 띠가 보이던 문제도 고쳤습니다.
- **페이지 탭 이름**: 탭이 첫 세션의 제목 대신 **페이지 1, 페이지 2, …** 로 표시됩니다. 그 페이지에 어떤 세션·문서가 있는지는 탭에 마우스를 올리면 나오는 툴팁과 스크린 리더용 이름에 남습니다.
- **페이지 탭 크기**: 옆의 실행 버튼과 같은 높이(30px)와 글자 크기(13px)로 키우고 좌우 여백을 넓혔습니다. 탭은 더 이상 줄어들며 글자를 자르지 않고, 헤더 폭이 620px 아래로 좁아질 때만 "페이지" 글자를 숨기고 숫자만 남깁니다. 승인·입력 대기 점은 그대로 탭 모서리에 뜹니다. 페이지 탭과 레이아웃 선택의 테두리가 정의되지 않은 변수를 읽어 글자색으로 떨어지던 것도 강조색으로 바로잡혔습니다.

**호환성**: 저장 형식과 IPC는 바뀌지 않았습니다. 테마 토큰에 `--accent`·`--tint-scale`·`--glow-scale`·`--shadow-rgb`·`--shadow-scale` 등이 추가됐고, 모든 토큰이 라이트 값을 갖는지와 전경색이 라이트 표면에서 4.5:1을 지키는지를 테스트가 계약으로 지킵니다. 페이지 탭의 접근성 이름이 "1페이지: …"에서 "페이지 1: …"로 바뀌었으므로, 탭 이름으로 UI 자동화를 하는 스크립트가 있다면 맞춰야 합니다.

**한계**: 라이트 터미널의 색 보정은 명암비가 모자라는 글자만 어둡게 하므로, CLI가 의도한 정확한 색과는 다를 수 있습니다. 페이지 탭은 숫자만 보여 주므로 어떤 세션이 어느 페이지에 있는지는 툴팁이나 대기 점으로 확인해야 합니다. 라이트 테마의 새 모습은 단위 테스트와 색 계약으로만 확인했고 화면 캡처 비교는 하지 않았습니다.

**검증**: Windows에서 커밋된 트리 사본으로 Vitest 248개 파일·2,514개 테스트와 타입 검사를 통과했습니다. 페이지 탭은 단위 테스트로 라벨·툴팁·대기 점을 확인했습니다. main CI의 Ubuntu 테스트와 Windows 2022·Ubuntu 22.04 desktop Electron E2E, Android 셸 빌드를 태그 전에 확인하고, 패키징은 릴리스 CI에서 수행합니다.
