# v1.35.1 — 모바일 화면이 상태바·내비게이션 바·키보드를 피한다

v1.35.0 모바일 컴패니언을 실제 폰에서 써 보고 나온 화면 배치 문제를 고친다. 동봉된 Android 앱이 **0.1.1**로 올라가므로, PC를 이 버전으로 업데이트하면 폰 앱 첫 화면에 업데이트 배너가 뜬다.

## 버그 수정

- **세션 화면이 상단 상태바와 하단 내비게이션 바 밑까지 깔렸다.** 앱이 시스템 바 높이만큼 WebView 자체에 여백을 줬는데, WebView는 자기 여백을 무시하고 페이지를 꽉 채워 그린다. 이제 WebView를 감싸는 틀에 여백을 줘서 화면이 두 바 사이에만 그려진다(여백은 앱 배경색).
- **키보드가 올라와도 화면이 그대로여서 입력창이 가려졌다.** 같은 원인이다. 이제 키보드 높이만큼 WebView가 실제로 줄어, 입력창과 빠른 키가 키보드 바로 위에 붙는다.
- 폰 브라우저로 `/mobile/`을 쓸 때도 키보드에 맞춰 페이지가 줄어든다(`interactive-widget=resizes-content`).

## 검증

- Android 단위 테스트와 서명된 release 빌드 통과
- 실기기 확인: 상태바·내비게이션 바 여백, 키보드가 올라올 때 입력창 위치, 셸 0.1.0 → 0.1.1 자가 업데이트 한 사이클
