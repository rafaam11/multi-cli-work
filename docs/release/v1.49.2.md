# v1.49.2 — 팬아웃·메모 보내기의 긴 프롬프트 제출 수정

프롬프트 팬아웃, 로컬 diff 메모 보내기, PR 드래프트 노트 보내기로 넣은 긴 프롬프트가 Claude·Codex 입력창에 남기만 하고 제출되지 않던 문제를 고쳤다.

- **원인**: 프롬프트와 그것을 제출하는 Enter를 한 덩어리로 써서 생긴 문제다. Claude는 긴 한 줄을 붙여넣기로 받으면서 끝의 Enter까지 붙여넣기의 일부로 삼켰다. Codex는 긴 한 줄과 여러 줄 프롬프트를 입력창에 둔 채 제출하지 않았다.
- **수정**: 본문을 쓰고 300ms 뒤에 Enter를 따로 쓴다. v1.49.1의 `jk send`·보드 전달과 같은 방식이며, 이제 프롬프트를 넣는 경로 네 곳(팬아웃, diff 메모, PR 드래프트 노트, jk 전달 큐)이 같은 함수를 쓴다.

실제 Claude Code·Codex에서 287자 한 줄과 여러 줄 프롬프트를 팬아웃과 같은 경로로 보냈다. 고치기 전에는 Claude의 긴 한 줄과 Codex의 두 경우가 제출되지 않았고, 고친 뒤에는 넷 모두 제출되어 답이 돌아왔다. 전체 단위 테스트 2,173개와 타입 검사를 통과했다.

저장 형식과 폰 앱은 바뀌지 않았다.
