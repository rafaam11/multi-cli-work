# v1.35.2 — 폰에서 터미널 과거 기록까지 스크롤

v1.35.1을 폰에서 쓰며 나온 스크롤 문제를 고친다. 모바일 화면은 PC가 서빙하므로 **PC만 업데이트하면 되고, 폰 앱(0.1.1)은 그대로다.**

## 버그 수정

- **폰에서 터미널의 과거 기록(스크롤백)까지 스크롤되지 않았다.** xterm은 손가락 드래그를 스크롤백 이동으로 바꿔 주지 않는다. 그래서 "📱 폰 크기로"를 끈 상태에서는 PC 크기 화면을 담은 틀만 한 화면 높이만큼 움직였고, 켠 상태에서는 아예 스크롤되지 않았다. 이제 세로 드래그를 직접 받아, 위로는 넘친 틀을 먼저 올린 뒤 스크롤백을 줄 단위로 거슬러 올라가고(최대 5,000줄), 아래로는 스크롤백을 최신 줄까지 내린 뒤 틀을 내린다. 가로 드래그는 전처럼 틀이 움직인다.
- codex처럼 화면 전체를 다시 그리는 CLI는 스크롤백이 쌓이지 않아 위로 밀어도 지난 출력이 나오지 않을 수 있다(claude·PowerShell·bash는 남는다).
