# v1.37.1 — App.tsx·ipc.ts 분할 (동작 변화 없음)

기능은 바뀌지 않는다. 가장 큰 두 파일을 역할별로 나눴다. 렌더러의 `App.tsx`(3,778줄)와 main의 `ipc.ts`(1,465줄)다. 다음 기능 작업이 한 파일에 몰리지 않게 하려는 것이다. 회귀가 생기면 원인을 이 릴리스로 좁힐 수 있도록 따로 낸다.

## 바뀐 구조

- **`App.tsx` 3,778줄 → 2,451줄.** 떼어 낸 코드는 `src/renderer/src/app/` 아래에 있다.
  - 상태 모델·복원 헬퍼: `app-model.ts`
  - 시작할 때 어느 폴더·세션·워크트리를 열지: `restore-plan.ts` — 새로 테스트를 붙였다.
  - 사이드바 폭·리사이즈: `use-sidebar-layout.ts`
  - 설정·테마·버전: `use-app-settings.ts`
  - 전역 단축키: `use-app-shortcuts.ts`
  - 사이드바 트리 펼침: `use-folder-tree.ts`
  - main 터미널 이벤트 구독: `use-terminal-events.ts`
  - 빠른 열기 목록: `quick-open-items.ts` — 새로 테스트를 붙였다.
  - App 상태를 받아 동작을 만드는 모듈 다섯: `grid-actions.ts`(그리드 배치), `session-actions.ts`(세션 시작·재개·중지·삭제), `file-tab-actions.ts`(파일 탭), `worktree-actions.ts`(워크트리), `document-actions.ts`(문서 패인·PR 리뷰 정리)
  - 확인 대화상자 다섯: `AppConfirmDialogs.tsx`
  - "진행 중 표시 → 실패하면 오류 표시" 틀이 일곱 곳에 반복돼 있었는데, 이를 `pending.ts` 하나로 모았다.
- **`ipc.ts` 1,465줄 → 649줄.** 서비스 게이트웨이 타입은 `ipc-gateways.ts`, 인자 검사기는 `ipc-validation.ts`로 옮겼다. `ipc.ts`에는 채널 등록만 남는다.
- `App.test.tsx`(151개)와 `ipc.test.ts`는 손대지 않고 그대로 통과한다.
