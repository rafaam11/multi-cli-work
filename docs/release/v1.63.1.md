# v1.63.1 — 브리프에서 Linear 프로젝트 업데이트 제거

세컨드브레인 역할 재정리(2026-11-23)에서, 프로젝트 상태와 주간 요약의 정본을 Notion 프로젝트 DB로 정했습니다. Linear 프로젝트는 PRJ-key로 이슈를 묶는 그릇으로만 쓰고, 아무도 Linear 프로젝트 업데이트를 쓰지 않습니다. 그래서 세션 브리프의 Linear 맥락에서도 이 부분을 뺐습니다.

- **세션 브리프 › Linear 맥락**
  - "프로젝트 상태"와 "지난 업데이트" 줄을 뺐습니다. v1.63.0에서는 늘 "업데이트 없음"으로 나오던 줄입니다.
  - 열린 이슈(최대 8개), 최근 댓글(5건), CLI 사용 지시는 그대로입니다.
- **Linear 조회**: 쿼리에서 프로젝트 업데이트를 빼서 한 번에 가져오는 양이 줄었습니다.

**호환성**
- 저장 형식·설정·IPC는 바뀌지 않았습니다.

**검증**
- Windows에서 Linear 관련 Vitest 30개와 타입 검사를 통과했습니다.
- 태그를 찍기 전에 main CI에서 Ubuntu 테스트, Windows 2022·Ubuntu 22.04 desktop Electron E2E, Android 셸 빌드를 확인합니다.
