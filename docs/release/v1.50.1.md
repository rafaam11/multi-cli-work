# v1.50.1 — 프로젝트와 세션 사이드바 정리

프로젝트 목록에서 태그별 묶음을 없애고, 세션 목록의 필터를 전체와 대기로 정리했다.

- **프로젝트**: 묶기 버튼과 자동 태그 묶음을 제거했다. 프로젝트가 바로 나열되며, 모두·접기·작업중으로 프로젝트와 폴더를 펼치거나 접는다. 이전에 태그 묶음을 접어 두었어도 프로젝트가 숨지 않는다.
- **세션**: 여기 필터를 제거했다. 전체는 작업공간의 세션·문서를 보여 주고, 대기는 입력·승인을 기다리는 세션만 보여 준다. 전체를 누르면 대기 필터가 해제된다. 이전 여기 설정은 적용하지 않는다.

기존 태그와 프로젝트·폴더·세션 데이터는 유지된다. 폰 앱은 바뀌지 않았다.
