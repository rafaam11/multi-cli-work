# v2.0.2 — 실패한 세션 재개와 데스크톱 터미널 입력 수정

v2.0.1 설치 후에도 기존 실패 세션이 계속 시작 중으로 남거나, 터미널을 눌러도 입력되지 않던 문제를 수정했습니다.

- 실행이 확실히 거절된 세션은 오류로 표시하며, 재개 버튼으로 다시 시작할 수 있습니다. 정상 종료된 세션도 다시 이어갈 수 있습니다. 전달 여부가 불명확하거나 실행 중인 세션은 중복 실행하지 않습니다.
- 기존 v2.0.0/2.0.1 호스트가 계속 실행 중이면 그대로 유지합니다. 재개한 실행을 기존 화면 위치에 열고 이전 실행 기록을 보존합니다. 같은 재개 요청을 반복해도 실행이 중복되지 않습니다.
- 호스트 관찰이 Claude/Codex 대화 ID를 지우지 않습니다. 재개 요청이 실패하거나 앱을 다시 열어도 원래 대화 연결을 보존합니다. v1에서 가져온 대화도 명시적으로 재개할 수 있습니다.
- 데스크톱에서 터미널 화면을 클릭하면 다른 사용자가 제어 중이지 않은 경우 제어권과 입력 포커스를 요청합니다. 단순히 화면을 열 때는 터미널 크기와 제어권을 바꾸지 않습니다.
- 세션 재개 시 이전 실행의 제어권과 화면 연결을 정리해, 새 실행에서도 입력·출력과 크기 조절이 이어지도록 했습니다.

업데이트는 실행 중인 호스트나 Claude/Codex 작업을 강제 종료하지 않습니다. 오래된 실패 세션은 업데이트 후 해당 세션의 **재개** 버튼을 누르세요.

Android 기능·실기기 검증은 사용자 요청대로 제외했습니다. Windows/Linux 검증 근거는 [출시 검증 기록](v2-validation.json)에 연결합니다.
