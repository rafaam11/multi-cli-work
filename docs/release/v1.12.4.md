# v1.12.4 — 사이드바 업무 프로젝트 행 정리

## 변경 사항

- 사이드바의 업무 프로젝트 그룹 행에서 구분 칩("정부지원과제", "외주개발", "상품개발", "기타")과 "폴더 N개" 카운트를 제거 — 행이 아이콘 + 이름 한 줄로 정리됨
- v1.12.0에서 도입한 구분별 색상은 그대로 유지 — 아이콘 색과 그룹 좌측 레일 색이 구분을 구별하는 신호로 남음
- 두 줄이던 행이 한 줄이 되면서 행 높이가 40px → 28px로 줄고, 미분류 행과 높이가 나란해짐
- 구분 텍스트는 홈 대시보드 카드와 업무 프로젝트 상세 페이지의 칩에 그대로 남아 있음 — 앱 전체 기준으로 구분이 색상으로만 전달되지는 않음

동작·데이터 형식 변경 없음. 사이드바 표시만 달라지며 `work-projects.json`을 비롯한 저장 파일 스키마는 그대로다.

## 릴리스 자산

- `Multi-CLI-Work-Setup-1.12.4.exe`
- `Multi-CLI-Work-1.12.4-linux-x64.deb` / `.AppImage`
- `latest.yml`, `latest-linux.yml` 및 Windows blockmap

## 검증

- 사이드바가 구분을 색상으로만 남기고 홈 카드는 계속 글자로 적는다는 단위 테스트로 기존 칩 테스트를 대체 (Vitest 73개 파일, 629개 테스트 통과)
- TypeScript typecheck 및 프로덕션 빌드 통과
- Electron E2E 15개 시나리오 통과
- 실제 앱을 띄워 네 구분을 나란히 확인 — 사이드바 트리에 구분 글자와 폴더 카운트가 없고, 아이콘 색은 정부지원과제 `rgb(224,122,114)` / 외주개발 `rgb(111,192,138)` / 상품개발 `rgb(106,166,224)` / 기타 `rgb(154,164,159)`로 유지, 좌측 레일 색도 유지, 행 높이 28px, 긴 이름은 말줄임 처리, 홈 대시보드 카드에는 구분 칩 4종이 그대로 표시
