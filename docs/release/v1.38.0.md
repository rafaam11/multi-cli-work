# v1.38.0 — 원격에서 워크트리 골라 세션 만들기, 호스트 패인의 크기 표시

원격 창이나 폰에서 새 세션을 만들 때 그 폴더의 **워크트리를 고를 수 있다.** 원격이 터미널 크기를 쓰는 동안에는 호스트 PC의 패인 머리줄이 그 사실을 알리고, 버튼 하나로 크기를 되찾는다.

설계: [`docs/superpowers/specs/2026-10-03-remote-pc-window-design.md`](../superpowers/specs/2026-10-03-remote-pc-window-design.md) · 사용법: [설치 문서의 "다른 PC에서 이어받기"](../installation.md#다른-pc에서-이어받기)

## 새 기능

- **워크트리를 골라 새 세션 만들기** (원격 창과 폰 공통)
  - **새 세션** 폼에서 폴더를 고르면, 그 폴더에 워크트리가 있을 때 **작업 위치**(루트 / 브랜치)가 나온다.
  - 목록은 사이드바와 같다. 봇 브랜치(dependabot 등) 워크트리와 디스크에서 사라진 워크트리는 빠지고, 만든 순서대로 나온다.
  - 폴더를 바꾸면 작업 위치는 루트로 돌아간다. 호스트 PC 화면의 선택과 배치는 그대로다.
  - 세션 목록에서 워크트리 세션은 이름 옆에 브랜치가 붙는다(예: "리팩터 · feat/search").
- **"<기기>에서 크기 사용 중"** — 원격 창의 자동 맞춤이나 폰의 "폰 크기로"가 터미널 크기를 가져가면, 호스트 PC 그 패인의 머리줄에 기기 이름과 **크기 되찾기** 버튼이 뜬다. 그동안 패인의 줄바꿈이 어긋나 보이는 이유를 알려 주는 표시다. 버튼을 누르면 그 세션에 입력할 때처럼 호스트가 크기를 되찾고, 원격 창에는 "호스트가 크기를 가져갔습니다"가 뜬다.

## 알아둘 것

- 원격 화면은 호스트가 내보내므로 **호스트 PC가 이 버전이어야** 작업 위치 선택과 브랜치 표시가 나온다. 폰 앱(셸 0.2.0)은 그대로다.
- 다른 폴더의 워크트리 id를 보내는 잘못된 요청은 호스트가 거절하고, 그 이유가 요청한 화면 아래에 뜬다.

## 검증

- 전체 Vitest 169개 파일 / 1,844개 테스트 통과
- TypeScript 검사와 프로덕션 빌드 통과
- Electron E2E 전체 28개 통과. 원격 창 e2e에 두 장면을 넣었다:
  - 실제 git 워크트리를 원격 창에서 골라 세션을 만들고, 호스트에서 그 세션이 그 워크트리에 묶였는지 확인
  - 원격이 크기를 가져가면 호스트 패인에 표시가 뜨는지, **크기 되찾기**로 사라지고 원격 창이 멈추는지 확인
