# v1.53.1 — 짧은 이름·링크로 연 레포도 최신화한다

v1.53.0은 릴리스 검증에서 걸려 배포하지 않았다. 이 버전이 업무 프로젝트 레포 일괄 최신화의 첫 배포다. 기능 설명은 [v1.53.0 노트](v1.53.0.md)에 있다.

- **레포 판정 수정**: 레포 최상위인지 확인할 때 경로 문자열을 그대로 비교했다. 그래서 8.3 짧은 이름(`RUNNER~1` 같은)이나 junction·심볼릭 링크로 가리킨 레포는 "git 레포 아님"으로 건너뛰었다. 이제 링크와 짧은 이름을 푼 실제 경로로 비교한다.
- **요약의 레포 이름**: Linux에서 Windows 경로를 받으면 요약에 레포 이름 대신 경로 전체가 나오던 것을 고쳤다.

**검증**: 타입 검사와 단위 테스트를 통과했다. junction으로 연 레포가 fast-forward되는 테스트를 추가했다.
