# v1.8.0 — GitHub PR 탭 안정화 및 Unified Diff 개선

## 변경 사항

- PR remote·상태·리뷰 요청 필터를 즉시 반영하고 검색에는 300ms debounce와 Enter flush 적용
- 요청 fingerprint와 sequence를 사용해 프로젝트·remote·필터·페이지네이션의 늦은 응답 차단
- 더 보기 중복 제거, 수동 refresh 캐시 우회, 30초 포커스 갱신과 현재 열린 PR 강조 추가
- PR 전환 시 상세·diff·댓글 초안·active review 상태를 격리하고 부분 오류 및 게시 실패 초안 보존 지원
- 상태·리뷰·checks 의미 배지, 변경 통계, GitHub 라벨 색상과 대비색을 포함한 상세 정보 계층 개선
- 변경 파일 화면을 `파일 목록 | 선택 파일 Unified Diff` 구조로 개편
- 파일 검색, 선택 보존, 이전·다음 및 `Alt+↑/↓` 이동, 저장되는 separator 폭 조절 지원
- hunk 기반 이전·새 라인 번호, 두 gutter, 추가·삭제·hunk 의미색과 가로 스크롤 지원
- binary·rename·신규·삭제·잘린 diff·no-newline 상태 및 인라인 스레드의 정확한 파일·라인 이동 지원
