# v1.36.1 — Codex 세션 재개 복구

Codex 세션의 **재개**를 눌렀을 때 `Codex resume ID 연결 실패: SessionStart hook을 /hooks에서 허용한 뒤 새 세션을 시작하세요.`라는 오류로 대화를 이어갈 수 없던 문제를 고친다.

## 버그 수정

- **종료 기록에서 대화 ID 복구** — SessionStart hook이 실행되지 않았더라도 Codex가 정상 종료할 때 출력한 `Session ID` 또는 `codex resume` 안내에서 정확한 ID를 저장한다. 이전 버전에서 ID가 빠진 세션도 재개 버튼을 누르면 저장된 종료 기록에서 복구한다.
- **기록이 없으면 대화를 직접 선택** — 강제 종료 등으로 복구할 ID가 없으면 Codex의 대화 선택 목록을 연다. 이어갈 대화를 고르면 같은 앱 세션에서 재개된다. 이 경우 자동 재개는 수동 선택을 기다린다.
- **빠르게 도착한 hook도 저장** — 재개할 터미널이 준비되기 전에 도착한 SessionStart 이벤트를 보관해 선택한 대화 ID가 누락되지 않게 한다. 곧바로 터미널이 종료된 경우에도 종료 상태를 유지하면서 해당 실행의 ID를 저장한다.
