# v1.54.1 — Codex 상태 칩과 시작 이벤트 누락 수정

v1.54.0은 Windows 릴리스 E2E에서 시작 이벤트 누락이 확인되어 배포하지 않았습니다. 이 버전이 Codex 상태·모델·권한·도구 칩의 첫 배포입니다.

- **Codex 상태와 칩**: MCW에서 직접 시작한 Codex 세션의 hook을 받아 모델·권한 모드·현재 도구를 패인 머리줄에 표시합니다. 프롬프트 제출·도구 호출 때 작업 중으로, 턴 종료·중단 때 입력 대기로 바뀝니다. 도구 반환이나 턴 종료 때 도구 칩을 지웁니다.
- **시작 이벤트 보존**: 첫 도구 호출이 빠르면 시작 이벤트가 최신 상태 파일에서 사라지던 문제를 고쳤습니다. 시작 정보를 별도로 보존하고, 터미널 생성 중 들어온 최신 도구·턴 이벤트도 시작 정보 뒤에 반영합니다.
- **정확한 세션 연결**: 현재 실행 세대와 대화 ID가 일치하는 시작 정보만 복원합니다. 이전 실행이나 다른 대화의 이벤트가 현재 세션을 바꾸지 않습니다. 컨텍스트 비율·비용·사용 한도는 추정하지 않습니다.
- **hook 신뢰**: 앱 소유 Codex 프로필의 hook 정의가 추가됐습니다. Codex가 신뢰 검토를 요구하면 `/hooks`에서 정의를 검토·승인하세요. HM v3.8.0의 선택형 `jinmin-codex` 패키지와 별도로 동작합니다.
- **함께 반영한 변경**: repo-sync 대체 엔진의 레포 판정·요약 동작을 harness-manager와 맞췄습니다.

**검증**: Windows에서 Vitest 228개 파일·2,304개 테스트와 타입 검사·프로덕션 빌드를 통과했습니다. 시작 정보 덮어쓰기, 터미널 생성 중 도구 이벤트 수신, 이전 실행 정보 배제와 시작 정보 중복 전달 방지를 회귀 테스트로 확인했습니다. Codex 화면 E2E는 10회 연속 통과했습니다. 격리된 실제 Electron·PTY·생성 hook·IPC를 연결하고 Codex 실행기만 모의 실행기를 사용했으며, 실제 계정의 모델을 호출하지 않았습니다. CI에서 Windows·Linux 전체 테스트와 E2E, Android 서명 셸 및 설치 파일 패키징을 추가 검증합니다.
