# v1.23.0 — 설정은 창에서, 단축키는 손에 맞게

지금까지 사용자 선호는 전부 코드에 하드코딩이었다 — 터미널 폰트·스크롤백·커서는 리터럴이고,
데스크톱 알림은 항상 켜져 있고, ✕는 항상 트레이로 숨고, 업데이트는 항상 시작 시 확인했다.
단축키도 코드 세 곳에 흩어져 있어서 메뉴의 표기와 실제 동작이 서로 다른 파일에 살았다.
이번 버전은 **설정 창**을 만들어 이 선호들을 전부 사용자 손에 넘기고, 단축키는 표시만이
아니라 **리매핑까지** 연다. 설정을 건드리지 않으면 앱은 이전 버전과 완전히 같게 동작한다.

## 변경 사항

- **타이틀바 "도움말" 옆에 "설정"이 선다.** 드롭다운이 아니라 버튼이다 — 누르면 인앱 모달
  설정 창이 바로 열린다. `Ctrl+,`와 빠른 열기(`Ctrl+P`)의 "설정 열기" 명령도 같은 창을 연다
- **저장 버튼이 없다.** 컨트롤을 바꾸는 순간 저장되고 적용된다. 좌측 세로 내비로
  일반 · 터미널 · 알림 · 단축키 네 카테고리를 오가고, ESC나 바깥 클릭으로 닫는다
- **일반** — 언어(한국어/English, 지금은 저장만 하고 다음 버전에서 적용), 창 닫기(✕) 동작
  (트레이에 남기기/앱 종료), 시작 시 이전 세션 자동 재개, 시작 시 업데이트 자동 확인.
  자동 확인을 꺼도 도움말 > 업데이트 확인은 그대로 동작한다
- **터미널** — 폰트 패밀리, 크기 8~32, 행간, 스크롤백 1,000~100,000줄, 커서 스타일(bar/block/
  underline), 커서 깜빡임. 바꾸면 **살아있는 모든 세션에 즉시 반영**된다 — 재시작도,
  새로고침도 필요 없다
- **알림** — 데스크톱 알림 마스터 토글과 상태별 토글(입력 대기 · 승인 대기 · 종료 · 오류).
  종료·오류 알림은 이번에 새로 생기는 능력이지만 기본이 꺼짐이라, 설정을 건드리지 않은
  사용자에게는 오늘과 같은 동작이다. 배지·트레이·창 attention은 알림 설정과 무관하게
  지금처럼 동작한다
- **키보드만으로 세션을 오간다.** `Ctrl+1`~`Ctrl+9`가 현재 화면의 슬롯 1~9를 포커스하고,
  `Ctrl+Tab`/`Ctrl+Shift+Tab`이 보이는 세션을 순환하며, `F5`가 선택된 세션을 새로고침한다.
  기존 키(Ctrl+P · Ctrl+S · Ctrl+=/-/0 · F11 · F12)는 전부 그대로다
- **단축키 탭에서 키를 클릭하면 캡처 모드로 들어가 다음 키 입력을 바인딩한다.** 이미 쓰는
  키를 넣으면 어느 액션과 충돌하는지 보여주고 기존 바인딩을 해제할지 묻는다. 항목별
  "기본값으로"와 전체 "모두 초기화"가 있다. 수식어 없는 단독 문자·숫자 키는 거부한다
  (터미널 입력과 충돌) — F1~F12 같은 기능키는 단독 허용
- **메뉴의 단축키 표기가 유효 키맵에서 파생된다.** 하드코딩 문자열을 지웠으므로 리매핑하면
  타이틀바 메뉴 표기가 따라온다. 동작과 표기가 어긋날 구조가 사라졌다
- **`edit.copy`/`edit.paste`/`edit.select-all`/`edit.clear`는 고정으로 표시되고 리매핑할 수
  없다.** 이 키들은 터미널 자체 의미론(선택 없는 Ctrl+C는 인터럽트)과 결합돼 있어, 옮기면
  표기만 바뀌고 동작이 남는 반쪽 리매핑이 되기 때문이다

## 호환성

- **settings.json이 없는 기동은 이전 버전과 구별할 수 없다.** 기본값 전체가 종전 하드코딩
  동작과 동일하다 — 트레이 상주, 자동 재개, 자동 업데이트 확인, 입력·승인 대기 알림 켬,
  종료·오류 알림 끔, 터미널 폰트 13px
- 설정은 userData의 `settings.json`에 저장된다(락 → 원자적 rename → 검증된 `.bak`).
  파서는 관용적이다: 모르는 필드는 버리고 빠진 필드는 기본값으로 채우므로, 파일이 파손돼도
  기본값으로 기동한다
- `keybindings`는 기본값과 다른 것만 저장한다. 기본 키맵이 바뀌는 업데이트에서 사용자가
  안 건드린 키는 새 기본값을 따라간다
- `~/.multi-cli-work/` 레지스트리 형식과 `state.json`의 내용은 바뀌지 않는다
