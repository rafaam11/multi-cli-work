# v1.27.1 — 사이드바 폴더 이름 표시 복구

v1.27.0에서 폴더를 트리의 잎으로 바꾸며 왼쪽 펼침 버튼을 제거했지만, 폴더 행의 옛 3열 레이아웃이
남아 있었다. 그 결과 폴더 선택 버튼 전체가 예전 펼침 버튼 자리인 26px 열에 갇혀 아이콘만 보이고
폴더 이름과 세션 수가 잘렸다.

## 변경 사항

- 폴더 행을 현재 구조에 맞는 단일 열로 바꿔 아이콘·폴더 이름·상태 배지가 사이드바 전체 너비를 쓴다
- 폴더 선택 버튼이 행 전체 너비를 차지하고 이름이 실제로 보이는지 Electron E2E에서 검증한다

## 릴리스 자산

- `Multi-CLI-Work-Setup-1.27.1.exe`
- `Multi-CLI-Work-1.27.1-linux-x64.deb` / `.AppImage`
- `latest.yml`, `latest-linux.yml` 및 Windows blockmap

## 검증

- Vitest 전체 통과 (106개 파일, 1151개 테스트)
- TypeScript typecheck 및 프로덕션 빌드 통과
- Electron E2E 전체 통과 (18개): 수정 전 폴더 행 약 229px에 선택 버튼이 26px로 잘리는 실패를
  재현하고, 수정 후 선택 버튼이 행 전체 너비를 쓰며 폴더 이름이 보이는 것을 확인
