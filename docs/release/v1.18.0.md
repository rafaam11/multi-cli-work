# v1.18.0 — 세로 열 그리드와 열별 분할, 화면을 두고 추가하는 세션

배치 모델이 프리셋 8종에서 **세로 열**로 바뀐다. 터미널의 정보는 아래로 흐르므로 기본 배치는 언제나
화면 높이를 온전히 쓰는 열이고, 위아래로 쌓는 일은 그리드 전체가 아니라 **그 열 하나**의 사정이 된다.
여기에 사이드바 우클릭으로 **보던 화면을 두고** 세션을 추가하는 경로가 함께 나간다.

## 변경 사항

- **레이아웃이 세로 열이 된다.** 레이아웃 타일이 프리셋 8종(전체·좌우·메인+우측2·3열·2×2·3열+우측
  2분할·메인+우측2×2·3×2) 대신 **1열~6열**을 고른다. 어느 쪽이든 패인은 좌우로 나란히 서고 화면
  높이를 전부 쓴다. 기본값 **자동**은 세션 수만큼 열을 세운다. 레이아웃은 더 이상 표에서 고르는
  것이 아니라 "열마다 몇 행"을 담은 배열에서 생성되며(`[1,2,1]` = 가운데 열만 분할), 미리보기 타일은
  그리드와 같은 `grid-template-*` 값을 그린다. 이전 버전이 저장한 프리셋 배치는 가장 가까운 열
  구성으로 이어진다
- **열 하나만 위아래로 나눈다.** 패인 헤더의 **분할 버튼**을 누르면 그 열만 2행이 되고 나머지 열은
  전체 높이를 지킨다. 다시 누르면 위쪽 패인이 열을 되찾고, 아래 패인은 그리드에서 빠지되 **세션은
  계속 돌고 사이드바 행도 남는다**. 분할은 열마다 한 번까지다 — 터미널을 한 번 더 반토막 내면 남는
  스크롤백이 볼 가치가 없어진다. 한 페이지는 6열 × 2행 = **최대 12칸**이고(이전 6칸),
  `terminals:set-visible-sessions` 계약의 상한도 12로 함께 올라간다
- **가장자리 스냅이 새 모델을 따른다.** 위=전체, 좌·우=2열의 그 절반, 모서리=2열을 모두 나눈 2×2의
  그 사분면. 조작과 미리보기는 그대로이고, 결과가 레이아웃 타일과 분할 버튼으로 손수 만들 수 있는
  배치와 정확히 같아졌다
- **폴더·worktree 우클릭에 새 세션이 생긴다.** 사이드바 폴더 행과 worktree 행의 우클릭 메뉴 최상단에
  설치된 에이전트가 전부 선다(`agents.json`으로 추가한 것 포함, 실행 파일이 없으면 이유를 달고
  비활성). 접힌 레일 상태의 폴더 버튼도 같은 메뉴를 띄운다
- **세션을 추가해도 보던 화면이 바뀌지 않는다.** 지금까지 세션을 만드는 모든 경로가 생성 직후 그
  세션으로 화면을 옮겼다 — 작업공간을 보고 있었다면 거기서 튕겨나오고, 다른 폴더의 그리드로
  갈아치워지고, 키보드 포커스까지 새 패인이 가져갔다. 우클릭으로 시작한 세션은 자기 폴더 그리드의
  다음 빈 칸을 받고 작업공간에도 담기지만 **페이지·선택·포커스·작업공간 인덱스는 그대로**다. 보고
  있는 그리드에 빈 칸이 있으면 그 자리에 조용히 나타나고, 이미 있던 패인은 밀려나지 않는다.
  사이드바 폴더 행의 짧은 펄스가 세션이 어디에 생겼는지 알려주는 유일한 신호다
- **재시작해도 원래 보던 곳이 열린다.** 세션 생성은 "다음 실행 때 복원될 선택"을 함께 갱신한다.
  조용히 만든 세션이 이것을 가져가면 화면은 안 바뀌었는데 재시작 후 가본 적 없는 폴더가 열린다.
  IPC에 `background` 플래그를 두어 이 경로만 선택 갱신을 건너뛴다
- **컨텍스트 메뉴가 창 밖으로 나가지 않는다(버그 수정).** 메뉴는 포인터 위치에서 열리므로 창 아래쪽에서
  연 긴 메뉴는 마지막 항목 — 하필 파괴적 동작이 있는 자리 — 이 화면 밖에 있었다. 이제 메뉴가 뜨기
  전에 창 안으로 되돌아오고, 창보다 큰 메뉴는 스크롤한다

## 검증

- Vitest 전체 통과 (85파일 872테스트) — 열 배열에서 만드는 레이아웃 생성·분할·병합 규칙, 슬롯 번호가
  분할 이후에도 유지되는지, 스냅 존이 새 모델로 내는 배치, `background` 생성이 저장된 선택을 건드리지
  않는지를 새 테스트로 덮었다
- TypeScript typecheck 및 프로덕션 빌드 통과
- Electron E2E 전체 통과 (17/17, 로컬 Windows) — 홈 대시보드를 띄운 채 폴더를 우클릭해 세션을
  시작했을 때 화면과 포커스가 그대로인지 확인하는 시나리오가 추가됐다
