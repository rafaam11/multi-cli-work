# v1.10.0 — 업무 프로젝트 계층 도입 (팀즈·노션·레포 통합)

## 변경 사항

- 폴더들을 실제 업무 단위(정부지원과제·외주개발·상품개발·기타)로 묶는 "업무 프로젝트" 계층 신설
- 사이드바가 업무 프로젝트 > 레포·문서 폴더 > 세션 계층으로 재구성, 미소속 폴더는 미분류 섹션 유지
- 드래그 또는 컨텍스트 메뉴로 폴더를 프로젝트 간 이동, 팀즈 문서 폴더는 책 아이콘으로 구분
- 업무 프로젝트 상세 페이지: 이름·구분·상태·노션 URL·메모 편집, 멤버 폴더 추가/제거, 노션·팀즈 폴더 빠른 열기, 소속 세션 현황
- 팀즈 문서 폴더 추가 픽커가 "팀즈 동기화 루트" 설정 위치에서 열림
- 홈 대시보드에 업무 프로젝트 카드(구분·상태·폴더 수·활성 세션 수) 추가
- 세션 시작 시 프로젝트 브리프(노션 URL·팀즈 경로·레포 목록)를 생성해 `MULTI_CLI_WORK_PROJECT_BRIEF` 환경변수로 전달, Claude 세션에는 SessionStart 훅 additionalContext로 자동 주입
- 소속 정보는 신규 `~/.multi-cli-work/work-projects.json`에 단독 저장 — `projects.json` 무변경으로 구버전 다운그레이드 안전

## 릴리스 자산
