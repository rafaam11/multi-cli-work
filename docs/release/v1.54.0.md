# v1.54.0 — Codex 세션 상태와 모델·권한 칩

Codex 세션이 작업 중인지 입력을 기다리는지 hook으로 확인하고, 패인 머리줄에 실제 관측한 모델·권한 모드·도구 이름을 표시합니다.

- **상태 전이**: 프롬프트 제출·도구 호출 때 작업 중으로, 턴 종료·중단 때 입력 대기로 바뀝니다. 도구 칩은 도구 반환이나 턴 종료 때 지웁니다.
- **정확한 세션 연결**: 세션 시작 때 확인한 대화 ID와 현재 실행 세대가 일치하는 이벤트만 상태와 칩에 반영합니다. 다른 대화나 이전 실행의 이벤트가 현재 패인을 바꾸지 않도록 했습니다.
- **표시 범위**: MCW에서 직접 시작한 Codex 세션에 적용합니다. 컨텍스트 비율·비용·사용 한도는 추정하지 않습니다.
- **hook 신뢰**: 앱 소유 Codex 프로필의 hook 정의가 추가됐습니다. 업데이트 후 Codex가 신뢰 검토를 요구하면 `/hooks`에서 정의를 검토·승인하세요. HM v3.8.0의 선택형 `jinmin-codex` 패키지와는 별도이며, 이 칩 기능에 해당 패키지 설치는 필요하지 않습니다.
- **함께 반영한 변경**: 기존 로컬 커밋의 repo-sync 대체 엔진 정리를 포함했습니다. harness-manager와 레포 판정·요약 동작을 맞춥니다.

**검증**: Windows에서 Vitest 228개 파일·2,301개 테스트, 타입 검사와 프로덕션 빌드를 통과했습니다. 격리된 실제 Electron·PTY·생성 hook·IPC·화면을 연결한 E2E에서 모델·권한·도구 칩과 턴 종료 후 입력 대기 전환을 확인했습니다. 이 E2E의 Codex 실행기는 모의 실행기이며 실제 계정의 모델은 호출하지 않았습니다. CI가 Windows·Linux 전체 테스트와 E2E, Android 서명 셸 및 설치 파일 패키징을 추가 검증합니다.
