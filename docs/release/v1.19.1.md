# v1.19.1 — 폴더 우클릭 메뉴에서 프로젝트로 이동 빼기

## 변경 사항

- **폴더 우클릭 메뉴의 `프로젝트로 이동`이 사라진다.** 이 블록은 등록된 **업무 프로젝트마다 한
  줄씩** 늘어나고 그 아래 `미분류로 이동`까지 달려 있어서, 프로젝트가 늘수록 메뉴가 길어지고
  실제로 자주 누르는 **Worktree 만들기**·**이름 변경**·**목록에서 제거**가 아래로 밀렸다. 이제
  메뉴는 **새 세션 → 파일 탐색기/VS Code/GitHub에서 열기 → Worktree 만들기 → 이름 변경/제거**로
  끝난다
- **폴더를 업무 프로젝트에 넣는 길은 그대로다.** 사이드바에서 폴더 행을 업무 프로젝트 위로
  **끌어다 놓는** 방법과, 업무 프로젝트 상세 페이지의 **프로젝트에서 제외**가 예전처럼 동작한다.
  메뉴 항목만 걷어냈을 뿐 뒤에 있는 `moveProjectToWorkProject` 경로는 두 곳에 그대로 남아 있다
