# v1.12.3 — 업무 프로젝트 하위 폴더 브랜드 아이콘

## 변경 사항

- 업무 프로젝트에 속한 폴더가 종류에 맞는 브랜드 마크를 달고 나옴 — 팀즈 문서 폴더(`docs`)는 Microsoft Teams 마크, GitHub 레포(`repo`)는 GitHub 마크
- 사이드바 트리와 업무 프로젝트 상세 페이지의 "구성 폴더" 목록 양쪽에 동일하게 적용
- 판별은 폴더에 지정된 역할(`role`) 값만 본다 — git remote나 경로를 검사하지 않으므로 추가 IPC·캐시·로딩 지연이 없음
- Teams 마크는 브랜드 보라색(`#6264a7`), GitHub 마크는 행의 텍스트색을 따라감 — 흑백 마크라 자체 색을 주면 배경에 묻힘. 폴더 행이 자식 아이콘을 일괄 착색하던 기존 규칙(사이드바 amber, 구성 폴더 teal)에서 두 마크만 빠져나옴
- 업무 프로젝트에 속하지 않은 미분류 폴더는 기존 폴더 아이콘과 펼침/접힘 표시를 그대로 유지
- 경로가 사라진 폴더는 역할과 무관하게 기존의 빨간 `FolderX` + "없음" 배지를 그대로 유지 — 브랜드 마크보다 우선

동작·데이터 형식 변경 없음. `work-projects.json`을 비롯한 저장 파일 스키마는 그대로이며 구버전으로 되돌려도 영향이 없다.

## 검증

- `TeamsIcon` 렌더링(크기 prop, className 전달)과 역할별 아이콘 분기·미분류 폴더 예외에 대한 단위 테스트 신규 추가 (Vitest 73개 파일, 629개 테스트 통과)
- TypeScript typecheck 및 프로덕션 빌드 통과
- Electron E2E 통과
- 실제 앱을 띄워 계산된 색을 확인 — 사이드바 Teams `rgb(98,100,167)` / GitHub은 행 텍스트색(amber 아님), 상세 페이지 Teams `rgb(98,100,167)` / GitHub은 행 텍스트색(teal 아님), 미분류 폴더 amber 유지, 경로 없는 폴더 `--red` 유지
