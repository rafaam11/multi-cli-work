# v1.63.0 — 세션 브리프에 Linear 맥락

할 일과 이슈를 Linear에서 관리하는 흐름에 맞췄습니다. 세션이 Linear의 맥락을 받은 채로 시작하고, 작업한 결과를 Linear에 남깁니다.

- **설정 › Linear**
  - Linear 개인 API 키(Personal API key)를 넣는 탭입니다. 저장하기 전에 Linear에 키가 맞는지 확인합니다.
  - 키는 OS 자격 증명으로 암호화해 `linear-credentials.json`에 저장합니다. 세션 환경변수로는 넘기지 않습니다.
  - 마지막 조회가 실패하면 그 사유를 한 줄로 보여 줍니다.
  - 토글 두 개: "브리프에 Linear 맥락 싣기", "커밋 후 기록 리마인드(Claude)".
- **세션 브리프의 Linear 맥락**
  - 폴더가 ws-root `PROJECT.yaml`의 `repos:`를 통해 PRJ에 속해 있으면 동작합니다. 그 폴더에서 Claude·Codex 세션을 열 때, 그 PRJ의 Linear 프로젝트 정보를 브리프에 싣습니다. Linear 프로젝트는 이름이 `PRJ-####`로 시작하는 것을 찾습니다.
  - 싣는 내용:
    - 프로젝트 상태
    - 열린 이슈 최대 8개: 이 레포의 `repo:` 라벨이 붙은 이슈를 먼저, 그다음 우선순위·기한 순
    - 최근 댓글 5건
  - 최대 3초 기다리고, 결과는 프로젝트마다 5분 동안 캐시합니다.
  - 키가 없거나 조회에 실패하면 이 절만 빠지고 세션은 평소대로 열립니다.
- **커밋 후 기록 리마인드(Claude)**
  - Linear 맥락이 실린 Claude 세션이 셸 도구(Bash·PowerShell)로 `git commit`을 실행해 HEAD가 실제로 바뀌면, 다음 턴이 끝날 때 리마인드를 한 번 보냅니다. 내용은 "관련 Linear 이슈에 댓글 1건으로 진행·결정·다음 할 일을 남겨라"입니다.
  - 같은 작업 트리를 쓰는 다른 세션의 커밋이나 pull·checkout에는 반응하지 않습니다.
  - Codex 세션에는 브리프에 지시 문장만 넣습니다.
- 세션은 `linear` CLI(`@schpet/linear-cli`)로 더 읽고 댓글을 남깁니다. 앱이 CLI를 설치하지는 않습니다.

**호환성**
- 새 설정 `general.linearBrief`·`general.linearRecordReminder`를 추가했습니다. 기본값은 켬이고, 키가 없으면 아무 효과가 없습니다. 이전 버전으로 되돌려도 모르는 필드는 버리므로 깨지지 않습니다.
- 새 파일: `userData/linear-credentials.json`, `userData/session-linear/`(리마인드 상태).
- 노션 토큰 저장소를 공용 암호화 저장소로 옮겼습니다. 파일 형식은 바뀌지 않았습니다.
- 외부 통신이 하나 늘었습니다. 키를 넣었을 때 세션 시작 브리프를 위해 `api.linear.app`을 조회합니다.

**한계**
- 폴더와 PRJ의 연결은 `PROJECT.yaml`의 `repos:`만 봅니다. 앱에는 수동으로 잇는 칸이 없으니 `/ws-link-repo`로 연결하세요.
- Linear 프로젝트는 이름 접두사로만 찾습니다.
- 커밋이 하나도 없는 새 레포의 첫 커밋은 리마인드하지 않습니다.
- 키를 지우거나 바꾼 직후에는, 그 전에 시작된 조회(최대 15초)가 캐시를 다시 채울 수 있습니다.

**검증**
- Windows에서 타입 검사와 Vitest 256개 파일·2,621개 테스트를 통과했습니다.
- Claude 상태 훅은 Windows(PS1)와 Linux(Python) 두 경로 모두 실제 git 레포를 대상으로 확인했습니다.
- 앱이 쓰는 Linear 쿼리를 실제 Linear에 보내, 오류나 복잡도 초과 없이 프로젝트를 찾는 것을 확인했습니다.
- 격리 인스턴스에서 확인한 것:
  - 키 저장
  - 키가 없을 때: 세션이 0.7초에 열리고 Linear 절이 없음
  - 키가 있을 때: Claude 1.5초, Codex 0.06초(캐시)에 열리고 Linear 절이 실림
- 태그를 찍기 전에 main CI에서 Ubuntu 테스트, Windows 2022·Ubuntu 22.04 desktop Electron E2E, Android 셸 빌드를 확인합니다.
