# v1.59.0 — 사이드바 프로젝트 아카이브와 우클릭 메뉴 정리

등록한 프로젝트가 많아도 사이드바를 지금 하는 일 위주로 유지할 수 있습니다. 세션과 폴더의 우클릭 메뉴도 정리했습니다.

- **프로젝트 아카이브**: 사이드바 업무 프로젝트 줄의 오른쪽 끝(마우스를 올리면 보임)에 있는 아카이브 버튼을 누르면, 그 프로젝트가 아래 폴더까지 통째로 목록 맨 아래 **아카이브** 칸으로 내려갑니다. 아카이브 칸의 같은 자리 버튼을 누르면 원래 순서 자리로 돌아옵니다. 아카이브 칸은 접힌 채 개수만 보이고, 비어 있으면 나타나지 않으며, 펼치면 목록을 밀어내지 않고 따로 스크롤됩니다.
- **세션 메뉴의 "파일 탐색기에서 열기"**: 사이드바와 패널 헤더의 세션 우클릭 메뉴에서 세션의 작업 폴더를 바로 탐색기로 엽니다.
- **메뉴 표시 수정**: 세션 우클릭 메뉴의 "다른 세션에 인계…"와 "대화 분기…"가 한 글자씩 세로로 쪼개져 보이던 문제를 고쳤습니다.
- **폴더 메뉴 정리**: 폴더 우클릭 메뉴에서 "Worktree 만들기"를 뺐습니다. 워크트리는 폴더 시작 페이지와 상세 페이지의 워크트리 칸에서 만듭니다.

**호환성**: 아카이브 목록은 사이드바 설정에 필드로 추가되며, 업무 프로젝트의 상태(진행중·보관 등) 값은 바꾸지 않습니다. 세션 작업 폴더를 여는 내부 IPC가 추가되었습니다. 그 밖의 저장 형식은 바뀌지 않습니다.

**한계**: 아카이브는 이 PC의 사이드바 목록에만 적용됩니다. 홈 대시보드, 원격 화면, 사이드바를 접었을 때의 폴더 바로가기에는 그대로 보입니다. 아카이브가 접힌 상태에서 그 안의 폴더로 이동해도 아카이브 칸이 자동으로 펼쳐지지 않습니다.

**검증**: Windows에서 Vitest 247개 파일·2,503개 테스트, 타입 검사, 프로덕션 빌드, desktop Electron E2E 34개를 통과했습니다. 격리 인스턴스에서 세션 메뉴 라벨의 한 줄 표시, 작업 폴더 열기, 아카이브 이동과 복원을 화면으로 확인했습니다. Linux E2E와 패키징, Android 셸 빌드는 릴리스 CI에서 수행합니다.
