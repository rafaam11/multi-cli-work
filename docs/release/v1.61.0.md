# v1.61.0 — 폰 화면은 터미널 중심으로, Claude Code는 앱 테마를 따라

폰(원격) 화면을 갤럭시 폴드처럼 세로가 짧은 기기에 맞춰 다시 짰습니다. 터미널을 폰 폭에 맞추고 버튼 줄을 줄여, 화면의 대부분을 터미널이 씁니다. 앱이 띄우는 Claude Code 세션도 이제 앱의 라이트·다크 테마를 따라가고, v1.60.0 라이트 테마에서 빠졌던 곳을 메웠습니다.

- **폰 터미널 폭 맞춤**: 세션을 열면 터미널을 폰 폭에 맞춰, PC 열 수 그대로 옆으로 넘치지 않습니다. PC에서 입력해 PC가 크기를 되찾으면 터미널 위에 "PC가 크기를 가져갔습니다 · 다시 맞추기"가 뜹니다. ⋯ 메뉴의 **PC 크기 유지**를 켜면 예전처럼 PC 열 수 그대로 그리며, 이 선택은 기기에 남습니다. `📱 폰 크기로` 버튼은 없어졌습니다.
- **머리줄 하나**: 경로 줄·머리줄·세션 칩 줄·도구 줄 네 줄을 44px 머리줄 하나(☰ · 제목과 상태·소속 · 대기 N · ⋯)로 합쳤습니다. 중지·재시작·이름 바꾸기·경로 복사·글자 크기·삭제는 아래에서 올라오는 ⋯ 메뉴로 옮겼고, 뒤로가기로 닫힙니다. 다른 세션으로는 ☰ 서랍이나 "대기 N"으로 옮겨 갑니다.
- **키 줄과 입력창**: 키를 자주 쓰는 순서로 놓고, 승인을 기다리는 세션이면 `1 2 3 Esc`를 맨 앞에 강조해 둡니다. 입력창은 한 줄에서 시작해 네 줄까지 늘어납니다.
- **펼친 화면(폭 600px 이상)**: 세션 목록이 왼쪽 레일로 늘 붙어 있고 머리줄이 없습니다. 키 줄과 입력창이 한 줄에 놓이며, 레일은 아이콘 폭으로 접을 수 있습니다.
- **키보드가 열렸을 때(높이 500px 미만)**: 키 줄을 ⌨ 버튼 뒤로 접고, 승인을 기다리는 세션이면 답할 키만 남깁니다.
- **목록·새 세션·페어링**: 목록 행이 두 줄(이름·상태 / 폴더·브랜치)이 되어 이름이 잘리지 않고, 답을 기다리는 세션이 맨 위에 묶입니다. 연결 해제와 호스트 목록은 ⋯ 메뉴 안으로 갔습니다. 새 세션은 에이전트를 아이콘으로 고르는 시트로 열립니다.
- **Claude Code 테마**: 앱이 띄우는 Claude Code 세션이 설정 ▸ 테마(시스템이면 OS 설정)를 따릅니다. 앱 전용 `claude-settings.json`에 테마를 실어 그 세션에만 적용하고, 사용자의 Claude 설정 파일은 읽기만 합니다. 색약·ANSI 계열을 고른 사용자는 그 계열 안에서 바뀌고, 사용자 정의 테마는 건드리지 않습니다. 설정 ▸ 일반의 "Claude Code 화면도 앱 테마 따라가기 — 새로 시작하는 세션부터"로 끌 수 있습니다(기본 켬). 실행 중에 `/theme`으로 바꾼 설정(색약 계열·사용자 정의)은 다음 세션에 반영되고, 읽을 수 없는 Claude 설정 파일은 "선택 없음"으로 보지 않고 그대로 둡니다.
- **라이트 테마 보완**: 폰 화면의 터미널도 데스크톱처럼 라이트에서 글자 대비를 4.5:1까지 끌어올리고, 마지막 줄 아래에 비치던 검은 띠를 없앴습니다. 브랜드 마크와 연결 점이 청록 바탕에 파란 테두리로 섞여 그려지던 것을 한 가지 역할의 색으로 정리했고, 로컬에서 바뀐 파일 표시가 선택된 행과 같은 파랑으로 보이던 것을 라이트에서는 청록으로 바꿨습니다(다크는 그대로 파랑).

**호환성**: 저장 형식과 원격 프로토콜은 바뀌지 않았습니다. 폰 화면은 PC 앱이 내주므로 PC를 업데이트하면 Android 앱은 그대로 새 화면을 받습니다. PC 브라우저(마우스)용 넓은 원격 화면은 바뀌지 않았습니다. 폰 화면의 "세션 목록으로"·"📱 폰 크기로"·"현재 세션 경로" 버튼과 세션 칩 줄이 없어지고 "세션 메뉴" 버튼과 "PC 크기 유지" 스위치가 생겼으므로, 이 이름으로 UI 자동화를 하는 스크립트가 있다면 맞춰야 합니다. Claude Code 테마는 새로 시작하는 세션부터 적용되고, 실행 중인 세션은 시작할 때의 테마를 유지합니다.

**한계**: 폰 화면은 폴드 크기를 흉내 낸 브라우저와 E2E로 확인했고, 실제 폴드 기기에서는 아직 확인하지 않았습니다. 폰이 터미널을 맞추면 PTY 크기가 하나뿐이라 PC 화면의 그 세션도 같은 열 수로 좁아지며, 폰이 그 세션을 떠나면 PC에 돌려줍니다. 펼친 화면의 레일에는 숨기기 버튼과 프로젝트 트리가 없어서 그 둘은 접은 화면의 목록에서 씁니다. Android 앱의 PC 목록 화면은 이번에 바꾸지 않았습니다.

**검증**: Windows에서 커밋된 트리 사본으로 Vitest 249개 파일·2,549개 테스트와 타입 검사를 통과했습니다. 폰 화면은 개편 커밋 직전 작업 트리에서 Windows 로컬 Electron E2E 4개(페어링·입력·자동 맞춤·터치 스크롤·서랍·세션 메뉴, 원격 창)를 통과했고, 폴드 크기(접음 476×672, 펼침 933×624, 각각 키보드가 열린 높이)를 흉내 낸 브라우저에서 가로 넘침이 없고 터미널이 접음 38줄·펼침 41줄(키보드가 열리면 18줄·22줄)을 쓰는 것을 확인했습니다. main CI의 Ubuntu 테스트와 Windows 2022·Ubuntu 22.04 desktop Electron E2E, Android 셸 빌드를 태그 전에 확인하고, 패키징은 릴리스 CI에서 수행합니다.
