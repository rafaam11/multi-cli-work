# v1.12.7 — worktree 동기화 경합과 gh 타임아웃 수정

## 변경 사항

- **동기화 진행 중 만든 worktree가 사라질 수 있던 경합을 고쳤다.** 이전에는 진행 중이던 동기화가 시작 시점의 낡은 스냅샷으로 레지스트리 전체를 교체해, 그 사이 만든 worktree 항목이 유실됐다. 유실된 항목은 다음 동기화에서 **새 id로** 다시 등록되므로, 원래 id를 참조하던 세션이 고아가 될 수 있었다
- 레지스트리 쓰기가 전체 교체에서 **델타 적용**으로 바뀌었다. 락 안에서 현재 레지스트리 위에 추가·삭제만 반영하므로 동시에 들어온 쓰기가 살아남고, 같은 경로가 이미 등록돼 있으면 중복 추가하지 않는다
- 동기화가 진행 중일 때 들어온 재요청은 완료 후 최신 프로젝트 목록으로 한 번 더 실행되고, 늦은 호출자는 그 최신 결과를 받는다
- **gh 타임아웃이 일반 실패와 구분된다.** GitHub PR 조회가 30초를 넘기면 "gh가 30초 안에 응답하지 않았습니다."로 표시된다. POSIX에서는 SIGTERM 후 5초 안에 종료되지 않으면 SIGKILL로 마무리해 프로세스가 남지 않는다
