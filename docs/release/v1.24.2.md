# v1.24.2 — 사이드바를 좁혀도 확인 버튼과 세션 배지가 잘리지 않도록

좌측 사이드바를 드래그로 좁히면 맨 아래 "최신버전 확인" 배지의 확인/재시작 버튼과, 레포 행의
활성 세션 숫자·"작업 중" 표시가 사이드바 밖으로 밀려나며 잘려 보이던 문제를 고쳤다.

## 변경 사항

- **`.project-sidebar`에 잘려나가던 우측 요소들이 더는 넘치지 않는다.** 그리드 컨테이너에
  `grid-template-columns`가 명시돼 있지 않아, 내부에서 가장 넓은 자식(확인 버튼이 포함된
  업데이트 배지 등)의 콘텐츠 폭에 맞춰 암시적 열이 자동으로 늘어나며 부모 그리드가 정해준
  고정 폭을 무시하고 있었다. `grid-template-columns: minmax(0, 1fr)`을 명시해 사이드바 자신의
  폭 안에서만 자식들이 줄어들도록 고쳤다
- 기존에 각 자식 요소(업데이트 배지의 버튼, 레포 행의 세션 배지 등)에 적용돼 있던
  `min-width: 0` / ellipsis 축소 규칙은 그대로 유지되며, 이번 수정으로 비로소 의도대로
  동작한다

## 호환성

- 순수 CSS 수정이며 동작, 상태, 저장 스키마, API 변경은 없다
- 사이드바 기본(264px) · 최소(200px) · 최대(420px) 너비와 접힌(rail) 상태의 표시는 그대로다
