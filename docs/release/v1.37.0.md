# v1.37.0 — 폰 잠금 중 세션 알림 (셸 0.2.0)

폰이 잠겨 있어도 **PC에서 돌고 있는 claude·codex 세션이 입력이나 승인을 기다리면 알림이 온다.** 알림을 누르면 그 세션 화면이 바로 열린다. 모바일 컴패니언 설계의 P3 단계다. 이번 릴리스에는 Android 셸 0.2.0이 동봉되므로, 폰 앱 첫 화면에 업데이트 배너가 한 번 뜬다.

설계: [`docs/superpowers/specs/2026-09-30-mobile-companion-design.md`](../superpowers/specs/2026-09-30-mobile-companion-design.md) §7 · 사용법: [설치 문서의 모바일 절](../installation.md#모바일android-컴패니언)

## 새 기능

- **폰 알림 (셸 0.2.0)**
  - 등록한 PC 전부에 상태 연결을 하나씩 유지한다. 터미널 출력은 받지 않고 세션 상태만 받는다. 연결하는 동안 상단에 "PC n대 연결됨 · 대기 m" 상주 알림이 떠 있다.
  - 세션이 **입력·승인 대기**에 들어서면 "<PC 이름> · <세션 이름>" 알림을 띄운다. 연결할 때 이미 기다리고 있던 세션은 알리지 않는다. 같은 대기는 한 번만 알리고, 대기가 풀리면 떠 있는 알림을 내린다. 판단 규칙은 PC 앱이 다른 PC 세션을 알릴 때와 같다.
  - **알림을 누르면 그 세션이 열린다.** 그 PC 화면을 보고 있었다면 화면을 다시 띄우지 않고 세션만 바꾼다.
  - **PC 앞에 있으면 생략**(기본 켜짐): PC 앱 창에 포커스가 있고 **2분 안에 입력이 있을 때만** 생략한다. 창을 켜 둔 채 자리를 비우면 폰으로 알림이 온다. 그 PC의 세션 화면을 폰에서 보고 있는 동안에도 생략한다.
  - 앱 첫 화면의 **알림 카드**에서 켜고 끄고, 종료·오류 알림을 켤 수 있다. PC마다 끄는 스위치도 있다. 알림 권한이 없거나 배터리 최적화 대상이면 카드가 알려 주고 설정 화면으로 안내한다.
  - 폰을 재부팅하거나 셸을 업데이트해도 다시 연결한다. Tailscale이 끊겼다가 돌아오면 바로 다시 붙는다(그 밖에는 최대 1분 간격으로 재시도).
- **호스트가 PC 앞에 사람이 있는지 알린다** — 원격 프로토콜의 `status` 메시지에 선택 필드 `presence`(`focused`·`active`·`away`)를 실었다. 하위 호환이라 프로토콜 버전은 그대로다.

## 바뀐 것

- 셸 안내 문구 "설정 ▸ 모바일"을 "설정 ▸ 원격"으로 고쳤다(v1.36.0에서 예고한 것).

## 알아둘 것

- **PC 앞에 있으면 생략**은 호스트 PC가 v1.37.0 이상이어야 동작한다. 구버전 호스트는 PC 앞에 있는지 알려 주지 않으므로 그 PC의 알림은 항상 온다. 알림 자체는 v1.35.x 호스트에도 온다.
- 처음 한 번 **알림 권한**을 허용해야 한다(Android 13 이상). 제조사 절전 기능(예: 삼성 "절전 앱")이 서비스를 멈출 수 있다. 잠금 중 알림이 늦거나 오지 않으면 이 앱을 배터리 최적화에서 빼 둔다. Tailscale 앱 자체가 절전으로 잠들어도 알림이 끊긴다.
- 포그라운드 서비스 타입은 `specialUse`다. 상시 연결을 위해서이고, `dataSync`에는 Android 15부터 하루 6시간 제한이 있다.
- 실기기 확인 예정: 잠금 중 대기 알림 → 탭하면 세션 열림, Tailscale 끊김·복구, 재부팅·셸 업데이트 뒤 자동 재연결, PC 2대 등록.
