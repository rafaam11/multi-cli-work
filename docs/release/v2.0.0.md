# v2.0.0 — Herdr 실행과 프로젝트 협업, v1.55.1 복귀

프로젝트 관제 화면은 유지하면서 실행을 독립 `mcw-host`와 Herdr로 옮겼습니다. 창을 닫아도 호스트의 작업은 계속되며, 다시 열면 같은 실행에 연결합니다. PC 재부팅으로 종료된 프로세스는 자동으로 다시 실행하지 않습니다.

- **프로젝트 협업**: 작업마다 새 대표를 만들고 Claude Code/Codex와 모델 프로필을 직접 선택합니다. 작업자는 최대 3명이며, 지정하지 않은 작업자는 대표와 같은 PC에서 실행합니다. 팀 메시지·질문·승인·작업자별 결과를 작업과 실행 시도에 연결해 보존합니다.
- **변경과 결과**: 대표는 프로젝트 브리프가 있는 전용 디렉터리에서, 쓰기 작업자는 각각의 worktree에서 시작합니다. 원격 저장소와 기준 커밋을 확인하며, 변경 합치기·최종 통합·배포는 사용자가 결정합니다. 결과 제출과 사용자 확인은 별도 상태입니다.
- **터미널**: MCW 안의 Canvas 화면에서 한글 입력·붙여넣기·선택·스크롤·마우스·이미지와 찾기·복사·새로고침을 사용합니다. 같은 세션을 여러 화면에서 볼 때 입력과 크기 제어권을 표시합니다. 관찰 화면은 터미널 크기를 바꾸지 않습니다.
- **여러 PC**: SSH로 연결한 PC를 프로젝트에 명시적으로 연결하고, 프로젝트 → 저장소 → 경로/worktree → 세션으로 탐색합니다. 전체/대기는 연결된 PC 전체를 집계합니다. 연결이 끊기면 마지막 관찰과 저장된 결과를 표시하며, 전달 여부가 불명확한 실행을 자동으로 반복하지 않습니다.
- **기존 자료 보존**: 프로젝트 자료·메모·Git 도구·보드·대화 기록을 유지합니다. 기본 프리셋은 새 작업 인터페이스를 사용하며, 사용자가 편집한 이전 명령 프롬프트는 원문을 보존하고 이관 필요를 표시합니다. v2의 `jk` CLI/MCP와 호환 별칭은 제공하지 않습니다.
- **폰 연결**: 폰은 각 PC의 인증된 게이트웨이에 직접 연결합니다. 최신 Android 셸은 호스트별 v1/v2 화면과 기존 pairing을 유지하며 APK 다운그레이드를 요구하지 않습니다.

## 업데이트와 복귀

기존 앱의 업데이트 확인으로 설치할 수 있습니다. 첫 실행 전에 종료된 v1의 실제 앱 데이터·레지스트리·Local Storage·mod 상태를 해시와 함께 백업하고 검증합니다. v2는 별도 데이터 루트를 사용합니다.

`설정 → 업데이트 → v1.55.1로 돌아가기` 또는 설치 폴더 밖에 보존한 독립 복구 실행기로 원본 v1.55.1에 복귀할 수 있습니다. 원본 복구 설치본과 검증값이 포함되어 있어 오프라인 복귀가 가능하며, 첫 v2 화면이 열리지 못한 경우에도 복구 실행기를 사용할 수 있습니다.

복귀는 관련 작업이 정리되고 각 호스트의 상태를 확인한 뒤 진행합니다. 업데이트 전 v1 데이터를 복원하되 v2 데이터·결과와 Git 코드·worktree·Claude/Codex 대화 기록은 보존합니다. 복원한 v1에서는 자동 업데이트 확인·세션 자동 재개·세션 시작 시 레포 동기화를 끕니다. 공유 설정을 사용자가 나중에 수정했다면 덮어쓰지 않고 충돌을 표시합니다. 다시 v2로 업데이트하면 보존된 v2 상태를 사용하고, 복귀 기간의 v1 변경은 자동으로 합치지 않습니다.

## 검증 범위

Windows·Linux 터미널과 독립 호스트, SSH 협업, 연결 유실 복구 및 Windows·deb·AppImage의 오프라인 복귀 왕복을 출시 검증 대상으로 관리합니다. 검증 근거와 대상 커밋은 [출시 검증 기록](v2-validation.json)에 기록합니다.

**Android 기능·실기기 검증은 사용자 요청에 따라 이번 출시에서 제외했습니다.** APK 빌드와 기존 서명 인증서 확인은 기기 기능 검증을 뜻하지 않습니다. 한글 입력 자동화는 Chromium composition 이벤트를 사용하며 물리 키보드의 OS IME 검증과 구분합니다.
