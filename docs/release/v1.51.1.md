# v1.51.1 — 원격 화면을 메인 창처럼

다른 기기에서 보는 원격 화면이 호스트의 숨김 선반을 따르고, 목록과 스타일을 메인 창 사이드바에 맞췄다. 넓은 화면에서는 세션을 최대 4칸 그리드로 나란히 본다.

- **숨김 반영**: 메인 창에서 ✕로 숨긴 세션은 원격 목록 맨 아래 접힌 "숨김 N"으로 모인다. 숨기거나 다시 표시하면 연결된 원격 화면에 바로 반영된다.
- **원격에서 숨기기**: 원격 목록의 각 행 끝 버튼으로 세션을 숨기거나 다시 표시한다. 호스트 메인 창의 선반이 함께 바뀐다.
- **사이드바식 목록**: 폴더별 묶음 대신 메인 창 세션 패널처럼 상태 순위와 최근 순으로 한 줄씩 나열한다. 에이전트 아이콘, 폴더·브랜치(윗줄과 같으면 생략), 대기 N 바로가기, 전체/대기 범위를 갖췄다.
- **스타일 통일**: 원격 화면이 메인 창과 같은 색 토큰과 상태 색을 쓴다. 기기의 밝은/어두운 설정을 따른다.
- **넓은 화면 그리드**: 목록에서 고른 세션이 빈 칸에 추가되고, 4칸이 다 차면 포커스 칸을 바꾼다. 칸 머리줄의 ✕로 닫고, 열어 둔 칸은 기기별로 기억한다. 입력 도구는 포커스 칸에만 보인다.
- **Windows PATH 정리**: PATH 항목에 섞인 따옴표 때문에 뒤쪽 도구(npm, node)를 찾지 못하던 문제를 고쳤다.
- **종료된 터미널 크기 조정**: 막 종료된 세션의 칸 크기를 바꿀 때 오류가 나던 문제를 고쳤다.

원격 화면은 호스트가 제공하므로 이 PC만 업데이트하면 된다.

v1.51.0 태그는 E2E가 예전 원격 목록 구조를 찾다가 실패해 배포되지 않았다. 이 버전이 같은 변경을 담는다.
