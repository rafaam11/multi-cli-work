# v1.12.6 — 사이드바 폴더 상태와 일괄 펼침

## 변경 사항

- 좌측 사이드바 "폴더" 행에 **직접 지정하는 상태**가 생겼다. 작업중은 노랑, 완료는 초록으로 왼쪽 두꺼운 바와 이름 옆 점에 표시된다. 완료한 폴더는 흐려져 뒤로 물러나고 마우스를 올리면 다시 또렷해진다
- 상태는 폴더 행 오른쪽 버튼이나 우클릭 메뉴에서 바꾼다. **세션이 무엇을 하고 있든 상태는 저절로 바뀌지 않는다** — 세션 행의 색은 예전 그대로 PTY 상태를 따라간다
- 상태 값은 `~/.multi-cli-work/projects.json`의 `status` 필드에 저장되므로 앱을 다시 켜도 유지된다. 이 필드는 레지스트리에 원래부터 있던 것이라 저장 파일 스키마는 그대로다
- 프로젝트 목록 위에 일괄 펼침 버튼 3개가 붙었다. **모두**(전부 펼치기) / **접기**(전부 접기) / **작업중**(작업중인 폴더만 펼치고 나머지는 접기). 업무 프로젝트와 폴더 두 계층에 걸리며, worktree를 펼쳐둔 상태는 건드리지 않는다
- "작업중"은 한 번 정리해 주는 동작이지 켜두는 필터가 아니다. 누른 뒤 원하는 대로 다시 펼치고 접을 수 있고, 그 결과가 저장된다
- **폴더 행에서 경로가 빠졌다.** 이름과 경로가 2줄로 붙어 있어 폴더가 늘수록 읽기 어려웠다. 경로는 메인 창 상단과 업무 프로젝트 상세 페이지에 그대로 나오고, 사이드바에서는 마우스를 올리면 툴팁으로 뜬다. worktree 행의 경로도 같은 이유로 빠졌다
- 행 높이가 48px에서 30px로 줄어 같은 높이에 폴더가 더 들어간다

## 알아둘 점

- 상태를 한 번도 지정하지 않은 폴더는 **작업중**으로 보인다. 새로 연 폴더도 마찬가지다
- 레지스트리를 손으로 고쳐 `보류`나 `보관`을 넣어둔 폴더가 있다면 사이드바에서는 작업중으로 읽힌다. 값 자체는 지워지지 않지만, 이 토글로 다시 만들 수는 없다
