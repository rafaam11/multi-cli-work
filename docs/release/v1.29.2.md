# v1.29.2 — 자동화 브랜치를 작업 목록에서 제외

Dependabot 등 자동화 브랜치가 사이드바에 작업 공간으로 나타나던 문제를 수정했다.
메인과 자동화 worktree만 있는 폴더는 메인만 있는 폴더처럼 세션을 바로 표시한다.

- Dependabot, Renovate, Greenkeeper, Depfu, ImgBot, Changesets release, GitHub merge queue, Snyk, release-please의 알려진 브랜치 패턴을 제외한다.
- 사이드바, 빠른 열기, 새 세션, 작업 공간 및 브랜치 선택에 같은 규칙을 적용한다.
- 일반 작업 브랜치와 실제 Git ref는 유지한다. 이미 열린 자동화 worktree의 세션과 문서도 유지하고, Git 패널에는 실제 선택한 작업 대상을 표시한다.

## 검증

- 자동화 worktree만 있는 경우와 일반 worktree가 섞인 경우의 UI 회귀 테스트
- 실제 Git 저장소에서 브랜치 선택 목록 및 ref 보존 검증
- 전체 Vitest, TypeScript 빌드, Windows Electron E2E 및 패키지 smoke 검증
