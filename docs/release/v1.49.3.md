# v1.49.3 — Codex 확인 창 뒤 '작업 중' 표시 수정

Codex 세션이 훅 신뢰 확인 창에 답한 뒤 실제로는 입력을 기다리는데도 패인에 계속 '작업 중'으로 보이던 문제를 고쳤다.

- **원인**: 확인 창에 답하는 Enter를 앱이 프롬프트 제출로 보고 세션을 작업 중으로 표시했다. 턴이 시작되지 않았으므로 Codex가 끝났다는 신호를 보내지 않았고, 표시는 다음 실제 턴이 끝날 때까지 남았다.
- **수정**: 터미널이 화면에서 첫 실행 확인 창(Claude 폴더 신뢰·권한 우회 경고, Codex 훅 신뢰·폴더 승인)을 알아보고, 창이 떠 있을 때 친 Enter는 상태를 바꾸지 않는다. 확인 창 감지는 `jk send` 전달 큐와 같은 것을 쓴다. 이 때문에 v1.49.1에서 전달 큐가 이 작업 중 상태를 건너뛰던 우회 처리는 지웠다.

실제 Codex로 확인했다. 훅 확인 창에 답한 뒤에도 세션이 대기 상태로 남았고, Claude 빌더가 MCP 도구로 보낸 글을 받아 `board_post`로 보드에 수신 확인을 올렸다. 전체 단위 테스트 2,176개, 타입 검사, Windows·Linux Electron E2E를 통과했다.

저장 형식과 폰 앱은 바뀌지 않았다.
